# 해진 곳을 꿰매는 법

> 동네 수선집 사장과, 할머니의 낡은 코트를 들고 온 무뚝뚝한 남자의 현대 로맨스.

## 기획 메모 (초안: 1화를 쓰며 잡은 방향이며 언제든 바꿀 수 있음)

### 주요 인물
- **서하윤 (29)**: 망원동 골목의 수선집 '꿰맴'의 주인. 대기업 디자인팀에서 일하다 번아웃으로 그만두고, 돌아가신 엄마가 하던 수선집을 이어받았다. 남의 옷은 꼼꼼히 고치지만 자기 마음의 해진 곳은 모른 척한다.
- **한도겸 (31)**: 건축사무소에서 일하는 설계사. 말수가 적고 표정 변화가 거의 없다. 요양원에 있는 할머니가 아끼던 코트를 고치러 '꿰맴'에 온다.

### 핵심 줄거리 (뼈대)
1. 비 오는 밤, 문 닫기 직전에 도겸이 코트를 들고 온다. (1화)
2. 코트 안감에서 오래된 편지 한 장이 나온다. 이 편지가 두 사람을 계속 엮는다.
3. 수선이 끝날 때까지 도겸이 여러 번 가게를 찾으며 가까워진다.
4. 하윤이 회사를 그만둔 진짜 이유, 도겸이 할머니 곁을 지키는 이유가 드러난다.
5. 서로의 '해진 곳'을 받아들이며 연결된다.
