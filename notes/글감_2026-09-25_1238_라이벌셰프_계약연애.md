# 로맨스 글감 노트 — 라이벌 셰프의 계약 연애

Sep 25, 2026 · 자동 생성 (템플릿: `로맨스_글감_노트_템플릿.md` 복제)

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 두 사람이 함께 문을 연 새 레스토랑의 오픈일 아침, 주방에서 현우가 다은이 만든 소스를 맛보지 않고 그대로 접시에 올린다.
- 마지막 대사 한 줄: **"이제 네 맛을 안 봐도 알아."**
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요?
  현우는 "완벽은 혼자 만드는 것"이라 믿던 사람에서 "완벽은 믿고 맡기는 것"임을 알게 됨. 다은은 아버지와 비교당할까 봐 늘 증명하려던 사람에서, 비교 없이도 자기 요리를 확신하게 됨.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요?
  가짜 연애였다는 사실이 언론에 터지면서 공동 팝업 레스토랑이 폐업 위기에 처하고, 상속 조건(6개월 이내 성공)도 무산될 상황에 놓인다.
- 둘이 가장 많이 상처 주는 장면은?
  인터뷰 도중 서로 무심코 상대의 약점(현우의 요리학교 중퇴 이력 / 다은의 "아버지 후광" 루머)을 공개적으로 들춰버리는 장면.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는?
  결말이 '블라인드 테이스팅 없이 서로를 믿는다'라면, 출발은 '같은 건물 1층·2층에서 서로의 요리를 깎아내리며 손님을 뺏는다'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| "이제 네 맛을 안 봐도 알아" (안 맛보고 믿음) | 둘 다 남의 요리는 절대 안 믿고 항상 재료 원산지부터 캐묻는 습관 | 3~5화 |
| 할머니가 남긴 낡은 레시피 카드(암호 같은 필체) | 1권에서 둘 다 카드를 처음 발견하지만 글씨를 못 알아봐 다투는 장면 | 8화 |
| "이제 네 맛을 안 봐도 알아" | 다은이 원망하듯 던지는 "넌 내 요리 맛도 안 보고 욕부터 하지" 대사 | 6화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 정전된 밤, 같은 건물 1층·2층 레스토랑 사장이 각자 촛불을 켜고 손님을 접대하다가 계단에서 마주친다.
- **떠오른 대사:** "네 소스엔 정성이 없어." / "내 정성은 네가 평가할 게 아니야."
- **떠오른 설정·관계:** 미슐랭 셰프와 그 아래층 비스트로 오너셰프가 라이벌 관계인데, 돌아가신 건물주 할머니의 유언장 조건(6개월간 연인 행세 + 공동 팝업 성공) 때문에 어쩔 수 없이 얽힌다.
- **어디서 왔나:** 셰프 서바이벌 예능, 미식 다큐멘터리에서 라이벌 셰프들이 결국 협업하는 장면을 보고.
- **가장 강하게 느낀 감정 하나:** 짜릿함 (+ 은근한 애탐)

> 씨앗은 어떤 모양이든 심어 두면 돼요. 감정 한 단어가 나중에 이야기의 나침반이 돼요.

## 2단계 · 로그라인과 트로프

**공식:** 건물 상속을 걸고 6개월간 연인 행세를 해야 하는 상황에 놓인 미슐랭 셰프 현우가, 바로 아래층 라이벌 셰프 다은을 만나지만, 서로의 자존심과 열등감 때문에 가짜 관계가 진짜가 되어 버릴까 봐 두려워한다.

- **로그라인:** 위와 동일
- **작품 가제목:** 『당신의 맛을 압니다』
- **장르:** 현대 로맨스
- **배경:** 요식업계 (한 건물의 1층·2층 레스토랑)
- **분위기:** 달달 / 힐링 (중반부는 약간 피폐)
- **핵심 트로프(최대 3개):** 계약(가짜) 연애, 라이벌에서 연인, 질투·삼각관계 약간

**자주 쓰는 트로프 예시 중 이번에 고른 것**

- 관계 시작: 가짜 연인 연기 (유언장 조건)
- 관계 구도: 라이벌·원수 → 연인
- 감정 장치: 죄책감·돌봄 (스캔들로 서로에게 피해를 줬다는 죄책감)

## 3단계 · 인물 카드

| 항목 | 주인공 A — 현우 | 주인공 B — 다은 |
| --- | --- | --- |
| 이름·나이·직업 | 이현우, 32세, 미슐랭 2스타 파인다이닝 셰프 | 강다은, 30세, 개인 비스트로 오너셰프 |
| 한마디 인상 (별명처럼) | "완벽주의 로봇" | "불도저" |
| 결핍·상처 | 요리학교 중퇴 후 "제대로 배우지 못했다"는 열등감 | 유명 셰프인 아버지와 늘 비교당하며 자란 상처 |
| 겉으로 원하는 것 | 최고의 셰프로 인정받기 | 아버지 그늘에서 벗어나 내 이름으로 인정받기 |
| 사실 필요한 것 | "실수해도 괜찮다"는 말 | 비교당하지 않고 있는 그대로 존중받기 |
| 연애를 막는 내면의 벽 | 도움을 요청하는 걸 약점이라 여김 | 도움받으면 "역시 혼자 못한다"는 증거라 여김 |
| 매력 포인트 (독자가 반하는 부분) | 손님 한 명 한 명의 취향과 알레르기까지 기억함 | 망친 요리도 즉흥으로 살려내는 순발력 |
| 말버릇·습관 | 재료 원산지부터 확인하는 습관 | "내 방식이 있어" |
| 상대에게만 보여 주는 모습 | 실수한 요리를 숨기지 않고 먼저 보여줌 | 아버지 얘기를 처음으로 꺼냄 |

> 짧은 예: 현우는 '완벽해야 인정받는다'고 믿고, 다은은 '비교당하지 않아야 나답다'고 믿는다. 둘 다 "있는 그대로 존중받은 적 없다"는 결핍이 겹쳐서, 서로가 서로의 빈자리를 알아본다.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 둘 다 겉으로는 완벽해 보이지만 사실 필사적으로 버티고 있다는 걸 서로만 알아본다.
- **이어질 수 없는 이유 – 외적 갈등:** 유언장 조건(6개월 내 팝업 성공), 언론·평론가의 시선, 실패하면 둘 다 건물을 잃는다.
- **이어질 수 없는 이유 – 내적 갈등:** 도움을 요청하지 못하는 자존심, 서로에게 들키고 싶지 않은 열등감.
- **두 사람의 힘의 균형:** 초반엔 미슐랭 스타를 가진 현우가 업계에서 우위. 스캔들 이후엔 다은의 SNS 팬덤과 대중적 지지가 더 큰 힘으로 역전된다.
- **둘만의 상징물:** 할머니가 남긴 낡은 레시피 카드 (암호 같은 필체, 둘이 함께 풀어야 해독됨)
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 따뜻한 뭉클함 + 대리만족 (라이벌이었던 두 사람이 각자의 자리에서도, 함께여서도 잘 되는 결말)

**해당 없음:** 남녀 로맨스라 BL/GL 체크리스트는 생략.

## 5단계 · 회차 구성

- **예상 분량:** 총 75화 (3권 기준)
- **연재 플랫폼(예정):** 미정 (웹소설 플랫폼 검토 필요)

| 구간 | 회차 (3권·약 75화 기준) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 1년 후, 두 사람 레스토랑 공동 기념일에 할머니 레시피로 만든 디저트를 재현 |  |
| 결말 | 3권 · 69~75화 | 새 레스토랑 오픈, 블라인드 테이스팅 없이 서로를 믿는 장면 | "이제 네 맛을 안 봐도 알아" |
| 절정 | 3권 · 59~68화 | 스캔들 수습, 기자회견에서 진심 고백, 레시피 카드 암호가 풀림 |  |
| 위기 | 2권 후반~3권 초 · 39~58화 | 가짜 연애였다는 사실이 들통, 팝업 실패 위기, 서로 상처 주는 인터뷰 사건 |  |
| 중간 전환 | 2권 중반 · 31~38화 | 정전된 밤, 서로의 요리로 손님을 함께 접대하며 처음으로 서로를 인정 + 첫 키스 |  |
| 전개 | 1권 후반~2권 초 · 13~30화 | 공동 팝업 준비하며 티격태격, 서로의 결핍을 조금씩 알아가는 에피소드 |  |
| 계기 | 1권 · 8~12화 | 할머니 유언장 공개, 레시피 카드 발견, 계약(가짜 연애+공동 팝업) 시작 |  |
| 도입 | 1권 · 1~7화 | 1층·2층 레스토랑의 손님 뺏기 경쟁, 정전된 밤의 첫 대치 장면 |  |

**회차 끝 훅(다음 화를 누르게 만드는 마지막 장면) 아이디어**

## 마무리 체크리스트

- [x] 로그라인 한 줄만 읽어도 '그래서 어떻게 됐는데?' 하는 궁금증이 생긴다
- [x] 두 주인공 모두 분명한 결핍과 원하는 것이 있다
- [x] 둘이 연인이 되지 못하는 이유가 '오해' 하나뿐이 아니다 (유언장 조건 + 자존심 + 열등감)
- [x] 중간 전환점(감정 인정) 장면이 정해져 있다 (정전된 밤, 첫 키스)
- [x] 결말에서 두 사람 모두 조금이라도 변해 있다
- [x] 미리 쓰고 싶은 장면이 최소 3개 있다
- [x] 친구에게 30초 안에 설명할 수 있다 ("건물 상속 걸고 가짜 연애하는 라이벌 셰프 이야기")
