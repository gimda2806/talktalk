# 글감 노트 · 반죽의 온도

## 끝에서 거꾸로 설계하기

**3권 (도착지)**
- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요? — 새벽 5시, 동네 빵집 '온기' 앞. 강이도가 갓 나온 첫 빵을 오하늘에게 건넨다.
- 마지막 대사 한 줄: "이번엔 내가 먼저 말할게요. 이거, 실패해도 돼요."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요? 하늘은 아무도 들이지 않던 새벽 주방에 이도를 들인다. 이도는 익명 뒤에 숨지 않고 자기 이름으로 글을 쓴다.

**2권 (가장 멀어진 지점)**
- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요? 하늘이 이도의 정체(예전 자신의 레스토랑을 혹평한 평론가)를 알게 되어 가게 열쇠를 뺏고 내쫓는다.
- 둘이 가장 많이 상처 주는 장면은? 이도가 "처음부터 취재 때문에 온 거였어요"라고 인정하는 순간. 하늘은 "그럼 그동안 나눠 먹은 빵도 취재였어요?"라고 묻는다.

**1권 (출발지)**
- 결말과 가장 반대인 출발 상태는? 하늘은 새벽엔 혼자, 가게 문을 걸어 잠그고 굽는다(누구의 평가도 받지 않으려고). 이도는 필명 뒤에 숨어 자기 이름을 밝히지 않는다.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| "이번엔 내가 먼저 말할게요. 실패해도 돼요." | 하늘이 1화에서 이도에게 "여긴 실패해도 되는 빵집이에요"라고 말함 | 1화 |
| 오래된 오븐 타이머 (혹평 기사가 나던 날 멈춘 채로 둔 것) | 하늘이 그 타이머를 고치지 않고 방치해 둔 이유를 이도가 궁금해함 | 5화 |
| 이도가 자기 이름으로 쓰는 첫 기사 | 이도가 필명 뒤에 숨는 이유(선배의 이름으로 나간 예전 혹평)를 밝힘 | 18화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 문 닫은 파인다이닝 셰프가 동네 빵집을 차렸는데, 밤마다 정체 모를 아르바이트생이 실패한 반죽만 골라 먹는다.
- **떠오른 대사:** "이거 실패작인데요." / "저는 실패한 것만 먹는 사람이라서요."
- **떠오른 설정·관계:** 예전에 자신을 혹평해 가게를 문 닫게 만든 평론가가, 정체를 숨긴 채 피해 당사자의 새 가게에 야간 알바로 들어옴.
- **어디서 왔나:** 새벽에 문 연 동네 빵집 냄새, "완벽하지 않아도 괜찮다"는 카피 문구에서.
- **가장 강하게 느낀 감정 하나:** 애탐 (들키면 끝나는 관계를 매일 밤 이어가는 조마조마함)

## 2단계 · 로그라인과 트로프

**공식:** 완벽을 두려워하는 빵집 사장 오하늘이, 자신을 무너뜨린 평론가 강이도를 만나지만, 이도가 정체를 숨긴 채 곁에 남아 있다는 사실 때문에 다시 사랑받아도 되는지 확신하지 못한다.

- **로그라인:** 혹평 하나로 레스토랑을 접고 동네 빵집을 차린 오하늘 앞에, 그를 무너뜨린 평론가 강이도가 정체를 숨긴 채 야간 알바로 나타난다. 매일 밤 실패한 반죽을 나눠 먹으며 가까워지지만, 이도가 다시 하늘의 가게를 평가해야 하는 순간이 다가온다.
- **작품 가제목:** 반죽의 온도
- **장르:** 현대 로맨스
- **배경:** 동네 빵집(야간 주방), 미식 잡지사
- **분위기:** 잔잔 · 달달 · 살짝 피폐(신분 숨김 파트)
- **핵심 트로프(최대 3개):** 신분 숨김, 원수(가해자·피해자)에서 연인으로, 돌봄

## 3단계 · 인물 카드

| 항목 | 주인공 A (오하늘) | 주인공 B (강이도) |
| --- | --- | --- |
| 이름·나이·직업 | 오하늘, 31세, 빵집 '온기' 사장 (전직 파인다이닝 파티시에) | 강이도, 33세, 미식 평론가 (야간엔 신분을 숨기고 알바) |
| 한마디 인상 | 웃을 때만 진심인 사람 | 뒷문으로 들어오는 사람 |
| 결핍·상처 | 완벽해야 사랑받는다는 강박, 혹평 이후 평가받는 것 자체가 공포 | 선배 이름으로 나간 혹평을 자기 것처럼 떠안고 산 죄책감 |
| 겉으로 원하는 것 | 아무에게도 평가받지 않고 조용히 굽는 것 | 정체를 들키지 않고 취재를 끝내는 것 |
| 사실 필요한 것 | 실패해도 여전히 좋아해 줄 사람 | 자기 이름으로 떳떳하게 서는 것 |
| 연애를 막는 내면의 벽 | "또 무너질까 봐" 곁을 주지 않음 | "내가 누군지 알면 널 잃는다"는 두려움 |
| 매력 포인트 | 실패작도 정성껏 포장해서 나눠 주는 다정함 | 아무리 사소한 반죽도 왜 실패했는지 정확히 짚어내는 눈 |
| 말버릇·습관 | 실패한 빵을 "이건 연습용이에요"라며 건넴 | 맛을 보기 전에 항상 눈을 감음 |
| 상대에게만 보여 주는 모습 | 새벽 주방에서만 웃는 얼굴 | 필명 뒤가 아니라 자기 목소리로 솔직하게 말하는 순간 |

> 짧은 예: 하늘은 '완벽해야 사랑받는다'고 믿고, 이도는 자기 이름을 걸고 정직하게 말하는 법을 하늘 곁에서 다시 배운다. 이러면 사건이 없어도 둘 사이에 긴장이 생겨요.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 이도는 하늘이 숨기고 싶어 하는 실패작까지 정확히 알아봐 주는 유일한 사람이다. 하늘은 아무 기대 없이 곁에 있어 주는 이도에게 처음으로 무장을 푼다.
- **이어질 수 없는 이유 – 외적 갈등:** 이도가 편집장으로부터 '온기'를 정식으로 취재·평가하라는 지시를 받는다.
- **이어질 수 없는 이유 – 내적 갈등:** 이도는 정체를 밝히면 곧 관계가 끝날 거라 믿고, 하늘은 다시 평가받는 상황 자체를 견디지 못한다.
- **두 사람의 힘의 균형:** 처음엔 이도가 하늘의 재기 여부를 쥐고 있는 쪽(평론가)이지만, 관계가 깊어질수록 하늘의 신뢰를 잃을까 두려워하는 이도 쪽으로 균형이 뒤집힌다.
- **둘만의 상징물:** 혹평 기사가 나던 날 멈춰 버린 오븐 타이머.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 실패해도 괜찮다는 다정한 안도감.

## 5단계 · 회차 구성

- **예상 분량:** 총 75화 (3권)
- **연재 플랫폼(예정):** 미정

| 구간 | 회차 (3권·약 75화 기준) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 재개업 1주년, 손님이 된 이도가 다시 실패작을 고르는 후일담 |  |
| 결말 | 3권 · 69~75화 | 이도가 자기 이름으로 정직한 재평가 기사를 쓰고, 새벽 빵집 앞에서 재회 확정 |  |
| 절정 | 3권 · 59~68화 | 이도가 편집장의 압박을 거부하고 정체를 스스로 밝힘 |  |
| 위기 | 2권 후반~3권 초 · 39~58화 | 하늘이 정체를 알고 열쇠를 뺏음, 이도가 잡지사를 그만두려다 만류당함 |  |
| 중간 전환 | 2권 중반 · 31~38화 | 오븐 타이머를 함께 고치며 첫 고백에 가까운 대화 |  |
| 전개 | 1권 후반~2권 초 · 13~30화 | 매일 밤 실패작을 나눠 먹으며 가까워짐, 이도가 취재 지시를 처음 받음 |  |
| 계기 | 1권 · 8~12화 | 이도가 정식으로 야간 알바 채용, 하늘의 신뢰를 얻기 시작 |  |
| 도입 | 1권 · 1~7화 | 하늘의 새벽 루틴과 폐업 트라우마, 이도가 신분을 숨기고 지원서를 냄 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 정전된 밤, 두 사람이 손전등 하나로 반죽을 마무리하는 장면
- [ ] 이도가 예전 혹평 기사를 몰래 인쇄해 매일 밤 주머니에 넣고 다니는 걸 하늘이 발견하는 장면
- [ ] 하늘이 처음으로 "실패해도 돼요"를 이도에게 직접 해 주는 장면

**회차 끝 훅 아이디어**

- 1화 끝: 이도가 이력서 이름 칸에 필명 대신 진짜 이름을 쓰려다 다시 지운다.
- 38화 끝: 하늘이 서랍 속에서 예전 자신의 레스토랑 혹평 기사를 발견하는데, 스크랩한 사람이 이도라는 걸 암시하는 메모가 붙어 있다.
