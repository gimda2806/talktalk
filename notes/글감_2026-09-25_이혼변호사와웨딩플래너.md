# 글감 노트 · 이혼 전문 변호사 × 웨딩플래너

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요? — 두 사람이 다니는 건물 옥상, 작은 결혼식. 하객은 다섯 명뿐.
- 마지막 대사 한 줄: "이번엔 계약서 없이, 그냥 약속만 할게요."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요? 서인은 '깨질 걸 아는 약속도 해 볼 수 있는 사람'이 되고, 지호는 '완벽하지 않은 결혼식도 진짜라는 걸' 받아들인 사람이 된다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요? 지호가 맡은 대형 웨딩이 파혼으로 끝나며 회사가 휘청이고, 서인이 그 파혼의 법률 자문을 맡았다는 사실이 드러나 지호가 배신감을 느낀다.
- 둘이 가장 많이 상처 주는 장면은? 지호가 "너한테는 처음부터 우리 결혼식도 계약서 한 장이었냐"고 묻고, 서인이 대답하지 못한 채 사무실을 나간다.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는? 결말이 '계약서 없이 약속한다'라면, 출발은 '서인이 모든 관계를 계약서로만 믿는다'는 상태.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 옥상에서의 다섯 명짜리 결혼식 | 1화에서 지호가 "나는 큰 결혼식만 믿는다"고 단언하는 장면 (나중에 스스로 뒤집힘) | 1화 |
| "계약서 없이, 약속만" 대사 | 서인이 어릴 때 부모님 이혼 서류를 몰래 읽던 기억 | 6화 |
| 서인이 먼저 청혼하듯 말 거는 장면 | 지호가 항상 먼저 다가오고 서인은 늘 한 발 물러났던 패턴 | 전개 구간 내내 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 같은 건물 엘리베이터, 위층엔 웨딩플래너 회사, 아래층엔 이혼 전문 로펌. 같은 커플이 양쪽에 각각 의뢰를 넣는다.
- **떠오른 대사:** "저는 이 결혼, 성사시키는 게 일이고요. 당신은 깨지는 게 일이잖아요."
- **떠오른 설정·관계:** 웨딩플래너 대표와 이혼 전문 변호사가 같은 건물, 같은 커플을 두고 정반대 입장에서 부딪힘.
- **어디서 왔나:** "결혼식장과 이혼 법정이 같은 건물에 있으면 어떨까"라는 뉴스 기사 제목에서.
- **가장 강하게 느낀 감정 하나:** 짜릿함 (정반대 직업의 충돌) + 애탐

> 씨앗은 어떤 모양이든 심어 두면 돼요. 감정 한 단어가 나중에 이야기의 나침반이 돼요.

## 2단계 · 로그라인과 트로프

**로그라인:** 이혼만 전문으로 다뤄 온 변호사 이서인이 같은 건물 위층 웨딩플래너 강지호를 만나지만, 같은 커플을 두고 결혼을 성사시키려는 쪽과 대비하려는 쪽으로 정반대에 서게 되면서, 서로에게만은 계약서 없이 마음을 믿어 볼 수 있을지 갈등한다.

- **작품 가제목:** 그 결혼, 반댈세다
- **장르:** 현대 로맨스
- **배경:** 오피스 빌딩 (아래층 이혼 전문 로펌 / 위층 웨딩플래닝 회사), 결혼식장, 가정법원
- **분위기:** 코미디 반, 잔잔 반 (초반은 티격태격, 후반은 먹먹)
- **핵심 트로프(최대 3개):** 라이벌·원수 → 연인, 직업 대비(카리스마 × 다정), 짝사랑·쌍방 오해

## 3단계 · 인물 카드

| 항목 | 주인공 A (이서인) | 주인공 B (강지호) |
| --- | --- | --- |
| 이름·나이·직업 | 이서인, 32세, 이혼 전문 변호사 | 강지호, 34세, 웨딩플래너 대표 |
| 한마디 인상 (별명처럼) | '눈물 없는 협상가' | '결혼식장의 소방관' (뭐든 진화해 냄) |
| 결핍·상처 | 어릴 적 부모님의 지독한 이혼 소송을 지켜봄 | 자기 결혼식 날 상대가 나타나지 않아 파혼당함 |
| 겉으로 원하는 것 | 로펌 파트너 승진, 완벽한 승소율 | 업계 1위 웨딩플래너 타이틀, 흠 없는 결혼식 |
| 사실 필요한 것 | 깨질 걸 알면서도 믿어 보는 용기 | 완벽하지 않아도 사랑은 진짜라는 확신 |
| 연애를 막는 내면의 벽 | "결혼은 결국 계약이고, 계약은 깨진다" | "다시 버려질 바엔 아무것도 약속하지 않는다" |
| 매력 포인트 (독자가 반하는 부분) | 의뢰인 앞에서는 냉정하지만, 아이가 얽힌 이혼 건에서는 몰래 야근하며 양육비 계산을 다시 해 줌 | 결혼식 당일 사고가 터져도 하객 아무도 눈치 못 채게 웃으며 수습함 |
| 말버릇·습관 | "감정은 증거가 안 돼요" | "제 결혼식엔 실패가 없어야죠" (라고 말해 놓고 매번 자기 얘기는 피함) |
| 상대에게만 보여 주는 모습 | 법정 밖에서 울어 본 적 없는데, 지호 앞에서만 목소리가 흔들림 | 항상 웃던 사람이 서인 앞에서만 파혼 이야기를 꺼냄 |

> 짧은 예: 서인은 '믿었다가 배신당하느니 처음부터 안 믿는다'고 믿고, 지호는 '한 번 더 믿어 보자'고 말해 주는 사람. 이러면 사건이 없어도 둘 사이에 긴장이 생겨요.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 서인은 지호가 실패해도 무너지지 않는 모습에 끌리고, 지호는 서인이 누구보다 냉정하면서도 약자 앞에서는 물러서지 않는 모습에 끌린다.
- **이어질 수 없는 이유 – 외적 갈등:** 같은 건물, 같은 업계 관계자들 사이에 소문이 도는 게 부담스럽고, 서인이 맡은 이혼 사건의 당사자가 지호의 고객이라 이해 상충이 생긴다.
- **이어질 수 없는 이유 – 내적 갈등:** 서인은 '연애는 결국 이혼으로 끝난다'는 직업병 같은 확신이 있고, 지호는 '또 버려질 바엔 청혼도 하지 않는다'는 두려움이 있다.
- **두 사람의 힘의 균형:** 초반엔 지호가 늘 먼저 다가가고 서인이 물러서는 쪽이지만, 2권 파혼 사건 이후엔 서인이 먼저 다가가야 하는 쪽으로 뒤집힌다.
- **둘만의 상징물:** 지호가 상담 때마다 내미는 웨딩 카탈로그 뒷면에 서인이 몰래 적어 둔 메모.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 냉소적인 사람도 다시 믿어 볼 수 있다는 안도감.

## 5단계 · 회차 구성

- **예상 분량:** 총 75화 (3권 기준)
- **연재 플랫폼(예정):** 미정

| 구간 | 회차 (3권·약 75화 기준) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 두 사람의 옥상 결혼식 1주년, 지호가 처음으로 계약서 없이 산 반지 |  |
| 결말 | 3권 · 69~75화 | 다섯 명만 초대한 옥상 결혼식. "계약서 없이, 약속만" |  |
| 절정 | 3권 · 59~68화 | 서인이 먼저 지호를 찾아가 파혼 트라우마를 마주하게 도움 |  |
| 위기 | 2권 후반~3권 초 · 39~58화 | 지호의 대형 웨딩 파혼, 서인이 그 사건 자문이었단 게 드러남 |  |
| 중간 전환 | 2권 중반 · 31~38화 | 같은 커플의 상담을 나란히 진행하다 첫 키스 |  |
| 전개 | 1권 후반~2권 초 · 13~30화 | 같은 건물 엘리베이터에서 계속 마주치며 티격태격, 점심 내기 |  |
| 계기 | 1권 · 8~12화 | 한 커플이 결혼식 준비(지호)와 혼전계약서 작성(서인)을 동시에 의뢰 |  |
| 도입 | 1권 · 1~7화 | 서인의 완벽한 이혼 승소, 지호의 완벽한 결혼식 진행이 같은 날 같은 건물에서 겹침 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 서인이 이혼 서류 검토하다가 몰래 지호네 웨딩 카탈로그를 넘겨 보는 장면
- [ ] 파혼 위기의 커플 앞에서 서인과 지호가 정반대 조언을 동시에 하다 서로를 쳐다보는 장면
- [ ] 지호가 처음으로 "나도 결혼 안 해 봤다"고 털어놓는 장면

**회차 끝 훅(다음 화를 누르게 만드는 마지막 장면) 아이디어**

- 1화 끝: 같은 커플이 로비에서 두 사람에게 동시에 인사하며 "두 분이 같이 봐 주시는 거죠?"라고 묻는다.
