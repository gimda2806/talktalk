# 글감 노트 · 베이스노트 (가제)

Sep 23, 2026 · 로맨스_글감_노트_템플릿.md 복제본

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 새로 문을 연 두 사람 공동 공방 오픈식. 다인과 이현이 나란히 서서 새 시그니처 향수 라벨을 붙이고 있다.
- 마지막 대사 한 줄: "이번엔 내 이름 먼저 써. 순서 바꾸지 마."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요? 다인은 '실수 없는 완벽한 향'에 대한 집착을 내려놓고 얼룩진 시향지도 향으로 받아들인다. 이현은 남의 취향에 맞추던 습관을 버리고 처음으로 '내 향'을 세상에 내놓는다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요? 다인의 공모전 출품작 베이스가 이현이 예전에 폐기했던 조합과 같다는 사실이 밝혀지며 표절 논란이 터진다. 이현은 다인을 지키려고 자신이 먼저 그 조합을 만들었다고 심사위원회에 신고해 버리고, 둘은 각자 다른 도시로 흩어진다.
- 둘이 가장 많이 상처 주는 장면은? 다인이 "네가 날 도와준 게 아니라 동정한 거였어?"라며 이현의 자기희생을 오해해서 쏘아붙이는 장면.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는? 결말이 '나란히 서서 함께 라벨을 붙인다'라면, 출발은 '서로의 시향지를 몰래 구겨서 버리는' 적대 관계.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 라벨에 두 사람 이름이 나란히 | 1권 초반, 이름을 가리는 블라인드 심사 지원서를 두고 둘이 실랑이 | 3화 |
| "이번엔 내 이름 먼저 써" 대사 | 1권 초반, 공방 문패 순서를 두고 벌이는 유치한 신경전 | 2화 |
| 얼룩진 시향지를 향으로 받아들이는 다인 | 1권, 실수로 얼룩진 시향지를 "실패작"이라며 구겨 버리는 장면 | 4화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 폐업 세일 중인 오래된 향수 공방, 마지막 남은 시향지 두 장을 두고 손이 부딪히는 순간
- **떠오른 대사:** "이 냄새, 어디서 맡아본 것 같은데." / "그럴 리가요. 이건 제가 만든 거니까요."
- **떠오른 설정·관계:** 신인 조향사 공모전 최종 후보 두 명이 같은 심사 결과로 한 달간 같은 공방을 나눠 쓰게 됨
- **어디서 왔나:** 향수 가게에서 시향지 두 장을 나란히 맡아 보다가 두 향이 묘하게 닮았다고 느낀 경험
- **가장 강하게 느낀 감정 하나:** 짜릿함 (그리고 은근한 질투)

> 씨앗은 어떤 모양이든 심어 두면 돼요. 감정 한 단어가 나중에 이야기의 나침반이 돼요.

## 2단계 · 로그라인과 트로프

**공식:** 신인 조향사 공모전 최종 후보로 한 공방을 나눠 쓰게 된(상황)에 놓인 완벽주의 조향사 서다인(주인공 A)이 취향을 잃은 전직 대기업 수석 조향사 강이현(주인공 B)을 만나지만, 서로의 향에서 같은 상처의 냄새를 맡아 버렸기 때문에(걸림돌) 이 감정이 진짜인지 향처럼 금방 날아갈 두려움인지(질문/긴장) 한다.

- **로그라인:** 위 문장 그대로
- **작품 가제목:** 베이스노트
- **장르:** 현대 로맨스
- **배경:** 폐업 직전 리모델링한 오래된 향수 공방, 조향 업계
- **분위기:** 달달 / 잔잔 (감각적인 후각 묘사 중심)
- **핵심 트로프(최대 3개):** 라이벌에서 연인, 강제로 공간을 나눠 씀(동거의 변형), 비밀(표절 논란)

**자주 쓰는 트로프 예시**

| 관계 시작 | 관계 구도 | 감정 장치 |
| --- | --- | --- |
| 계약 연애·계약 결혼 | 혐관에서 연인으로 ✅ | 짝사랑·쌍방 오해 |
| 재회(구연인·첫사랑) | 친구에서 연인으로 | 비밀 연애 |
| 같이 살게 됨(동거) ✅(공방 공유) | 상사·부하, 선배·후배 | 질투·삼각관계 |
| 가짜 연인 연기 | 라이벌·원수 ✅ | 기억상실·시한부 |
| 잡지 못한 이별 후 재회 | 카리스마 × 다정 | 죄책감·돌봄 |

## 3단계 · 인물 카드

| 항목 | 주인공 A (서다인) | 주인공 B (강이현) |
| --- | --- | --- |
| 이름·나이·직업 | 서다인, 27세, 독립 조향사 | 강이현, 29세, 대기업 향수 브랜드 퇴사한 조향사 |
| 한마디 인상 (별명처럼) | '실패를 모르는 애' | '남의 향만 만들던 사람' |
| 결핍·상처 | 어릴 적 화재 사고로 후각을 잃을 뻔했던 경험이 있어 '완벽한 향'에 집착함 | 대기업에서 고객 취향에 맞춘 향만 만들다 자기 정체성을 잃음 |
| 겉으로 원하는 것 | 이번 공모전 대상 | 조용히 이번 라운드만 통과하는 것 |
| 사실 필요한 것 | 실수해도 괜찮다는 확신 | 남의 취향이 아닌 '내 향'을 만들 용기 |
| 연애를 막는 내면의 벽 | 감정에 흔들리면 후각(집중력)이 무뎌진다는 믿음 | 누군가를 곁에 두면 또 자기를 잃을 거라는 두려움 |
| 매력 포인트 (독자가 반하는 부분) | 실수한 시향지도 끝까지 분석해서 답을 찾아내는 집요함 | 다인이 놓친 감정의 결을 정확히 짚어내는 섬세함 |
| 말버릇·습관 | 향을 맡기 전 눈을 감고 셋을 센다 | 자기 향수에는 절대 이름을 붙이지 않는다 |
| 상대에게만 보여 주는 모습 | 실패작 시향지를 몰래 버리지 않고 서랍에 모아 둔다 | 처음으로 자기 이름을 건 향을 다인에게만 먼저 맡게 한다 |

> 다인은 '완벽해야 살아남는다'고 믿고, 이현은 '틀려도 그게 너만의 향'이라고 말해 주는 사람. 이러면 사건이 없어도 둘 사이에 긴장이 생겨요.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 다인이 숨기고 싶어 하는 '실패한 조합'을 이현은 오히려 가장 먼저 알아채고 흥미로워한다. 서로의 향에서 자신도 모르던 감정을 읽힌다는 감각.
- **이어질 수 없는 이유 – 외적 갈등:** 같은 공모전 최종 경쟁자라 심사 규정상 협업이나 사적 교류가 금지되어 있음
- **이어질 수 없는 이유 – 내적 갈등:** 다인은 감정에 흔들리면 실력이 무너진다고 믿고, 이현은 곁을 내주면 또 자신을 잃을까 두려워함
- **두 사람의 힘의 균형:** 초반엔 경력과 경험에서 이현이 앞서지만, 공모전 룰에서는 신선한 시선을 가진 다인이 유리해지며 균형이 뒤집힌다
- **둘만의 상징물:** 얼룩진 시향지 한 장 (버리지 않고 서랍에 모아 둔 첫 번째 '실패작')
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 실수도 나만의 향이 될 수 있다는 따뜻한 안도감

## 5단계 · 회차 구성

- **예상 분량:** 총 50화 (2권 기준)
- **연재 플랫폼(예정):** 미정 (카카오페이지/리디 등 검토)

| 구간 | 회차 (2권·약 50화 기준) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 오픈식 이후 첫 겨울, 함께 만든 향수가 매진되는 날 |  |
| 결말 | 2권 · 46~50화 | 공방 오픈식, 라벨에 두 이름을 나란히 붙임 |  |
| 절정 | 2권 · 39~45화 | 표절 논란의 진실이 밝혀지고 이현의 자기희생이 드러남 |  |
| 위기 | 1권 후반~2권 초 · 26~39화 | 표절 논란 폭발, 오해로 갈라섬, 각자 다른 도시로 |  |
| 중간 전환 | 1권 후반 · 21~25화 | 같은 시향지 향을 두고 첫 고백에 가까운 대화 |  |
| 전개 | 1권 · 9~20화 | 공방을 나눠 쓰며 서로의 결핍을 눈치채는 밀당 |  |
| 계기 | 1권 · 5~8화 | 최종 후보 발표, 강제로 한 공방을 나눠 쓰게 됨 |  |
| 도입 | 1권 · 1~5화 | 폐업 세일 공방에서의 첫 충돌, 시향지 다툼 |  |

**꼭 넣고 싶은 장면 목록**

- [x] 시향지 두 장이 뒤섞여 누구 것인지 모르게 된 밤
- [x] 이현이 다인의 '실패작 서랍'을 몰래 발견하는 장면
- [ ] 표절 논란 청문회 장면
- [ ] 다인이 얼룩진 시향지로 출품작을 완성하는 마지막 장면

**회차 끝 훅(다음 화를 누르게 만드는 마지막 장면) 아이디어**

- 1화 끝: 두 사람이 집어 든 시향지가 사실 같은 향이었다는 걸 동시에 깨닫는 순간
- 25화 끝: 이현이 "이거, 네 실패작 서랍에 있던 그 향이잖아"라고 말하며 자기가 쓴 신고서를 내미는 순간

## 마무리 체크리스트

- [x] 로그라인 한 줄만 읽어도 '그래서 어떻게 됐는데?' 하는 궁금증이 생긴다
- [x] 두 주인공 모두 분명한 결핍과 원하는 것이 있다
- [x] 둘이 연인이 되지 못하는 이유가 '오해' 하나뿐이 아니다 (심사 규정 + 각자의 두려움)
- [x] 중간 전환점(감정 인정) 장면이 정해져 있다
- [x] 결말에서 두 사람 모두 조금이라도 변해 있다
- [x] 미리 쓰고 싶은 장면이 최소 3개 있다
- [x] 친구에게 30초 안에 설명할 수 있다
