# 글감 노트 · 라이벌 빵집 가짜 연인

Sep 25, 2026 · [로맨스_글감_노트_템플릿.md](로맨스_글감_노트_템플릿.md) 사용

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 새벽 여섯 시, 나란히 붙은 두 빵집 셔터가 동시에 올라간다. 한쪽 유리문에 어젯밤 붙은 "폐업 세일" 종이가 아직 테이프도 안 말랐다.
- **떠오른 대사:** "우리 집 팔리면 너희 집도 옆에서 못 버텨. 셔터 내리기 싫으면 나랑 사귀는 척해."
- **떠오른 설정·관계:** 3대째 골목을 지켜온 두 빵집 자녀가, 프랜차이즈에 상권을 넘기려는 건물주와 재개발 조합을 막으려고 가짜 커플 행세를 한다.
- **어디서 왔나:** 동네 재개발로 오래된 가게들이 한 번에 없어지는 뉴스, 그리고 매일 아침 같은 시간에 셔터를 여는 옆집 사장님들.
- **가장 강하게 느낀 감정 하나:** 짜릿함 (라이벌인데 한편이 돼야 하는 아이러니)

> 씨앗: '적이었는데 같은 편을 해야 한다'는 설정 하나로 시작.

## 로그라인과 트로프

**공식:** 3대째 이어온 골목 빵집 '해뜨는집'의 막내 **지안**이, 재개발 조합에 넘어갈 위기에 놓인 라이벌 빵집 '아침빵'의 아들 **태오**를 만나지만, 상권을 지키려면 **가짜 커플 행세**를 해야 하는 상황 때문에 **진짜 마음이 자꾸 새어 나오는 걸 숨길 수 있을까** 한다.

- **작품 가제목:** 「셔터는 같이 올린다」
- **장르:** 현대 로맨스
- **배경:** 오래된 골목 상권, 빵집 두 곳이 나란히 붙은 거리
- **분위기:** 달달 + 코미디, 중반부는 잔잔
- **핵심 트로프(최대 3개):** 가짜 연인 연기, 라이벌 → 연인, 계약 관계(상권 지키기 동맹)

## 3권 → 1권 역순 설계

**3권 (도착지)**
- 마지막 장면: 재개발이 무산되고, 두 빵집이 벽을 텄던 자리에 공동 카운터를 놓은 '해뜨는집 × 아침빵' 오픈일 아침.
- 마지막 대사: "이제 진짜 사귀는 척 그만해도 되는데. …계속 손님인 척할 거야?"
- 변화: 지안은 '가업은 나 혼자 지켜야 한다'는 고집을 내려놓고 도움을 받아들이게 되고, 태오는 도망치듯 웃어넘기던 버릇 대신 자기 가게를 먼저 지키겠다고 나서는 사람이 된다.

**2권 (가장 멀어진 지점)**
- 잃는 것: 조합원 서명이 새어 나가면서 '가짜 연애'였다는 사실이 동네 전체에 소문나고, 태오네 집은 결국 매매 계약서에 도장을 찍는다.
- 가장 상처 주는 장면: 지안이 "너희 집 파는 거 나랑은 상관없잖아"라고 선을 긋고, 태오는 "그럼 우리가 한 건 다 거래였네"라고 되받아친다.

**1권 (출발지)**
- 결말과 가장 반대인 출발: 결말이 '나란히 문을 여는 두 가게'라면, 출발은 '서로 인사도 안 하고 셔터만 노려보는 두 집'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 공동 카운터 오픈, 두 가게 벽을 튼 자리 | 1화에서 두 가게 사이 벽에 실금이 가 있다는 묘사 (건물이 원래 하나였다는 복선) | 1화 |
| "손님인 척할 거야?" 대사 | 가짜 연애 초반, 태오가 매일 지안 가게에 손님으로 와서 계산만 하고 도망가는 습관 | 9화 |
| 지안이 도움을 받아들이는 변화 | 지안 엄마가 "너는 다 혼자 하려고 해서 탈이다"라고 지적하는 장면 | 4화 |

| 결핍·상처 | 아빠가 가게를 두고 떠난 뒤 '내가 안 지키면 없어진다'는 강박 | 자기가 회사를 그만두게 만든 게 자기 탓이라 여기는 죄책감, 그래서 뭐든 쉽게 놓아 버림 |
| 겉으로 원하는 것 | 재개발을 막고 가게를 지키는 것 | 골치 아픈 가업을 빨리 정리하는 것 |
| 사실 필요한 것 | 혼자 다 짊어지지 않아도 된다는 확인 | 뭔가를 끝까지 지켜 본 경험 |
| 연애를 막는 내면의 벽 | "가게를 뺏길지도 모르는 지금, 마음 쓸 여유는 사치다" | "내가 좋아하는 건 결국 다 망가뜨린다" |
| 매력 포인트 | 손님 이름과 좋아하는 빵을 다 외우는 다정함 | 위기에서 실없는 농담으로 분위기를 풀어 주는 여유 |
| 말버릇·습관 | 곤란하면 반죽부터 치댄다 | 진심을 말할 때만 존댓말이 튀어나온다 |
| 상대에게만 보여 주는 모습 | 새벽에 몰래 태오네 매대에 실패한 시식빵을 놓고 감 | 지안 몰래 조합 사무실에 가서 혼자 언성을 높임 |

## 관계와 갈등

- **끌리는 이유:** 둘 다 '가게 = 가족을 지키는 방법'이라 믿는 사람들이라, 서로의 절박함을 한눈에 알아본다.
- **외적 갈등:** 재개발 조합, 건물주, 계약서 마감 기한.
- **내적 갈등:** 지안은 도움을 받는 것을 패배로 여기고, 태오는 지키려는 마음이 생길수록 도망칠 핑계를 찾는다.
- **힘의 균형:** 초반엔 지안이 가게를 지킬 의지가 훨씬 강해 태오를 끌고 다니지만, 태오가 먼저 계약서에 도장을 찍으려던 순간 지안이 말리면서 뒤집힌다.
- **둘만의 상징물:** 매일 아침 서로의 매대에 몰래 놓아두는, 실패해서 팔 수 없는 빵 조각.
- **끝났을 때 독자가 느낄 감정:** 따뜻함과 안도감 — 오래된 것도 지킬 수 있다는 위안.

**꼭 넣고 싶은 장면 목록**

- [ ] 정전된 새벽, 두 가게 반죽을 같이 치대며 처음으로 길게 대화하는 장면
- [ ] 조합 총회에서 지안이 태오 대신 나서서 발언하는 장면
- [ ] 실패한 시식빵이 사실 서로에게 보내는 편지였다는 게 밝혀지는 장면

**회차 끝 훅 아이디어**

- 태오가 매매 계약서에 도장을 찍기 직전, 지안이 문을 밀고 들어오며 "잠깐만요" 하는 데서 컷.
