# 글감 노트 · 결혼과 이혼 사이

Sep 24, 2026 · [로맨스_글감_노트_템플릿.md](로맨스_글감_노트_템플릿.md) 기반으로 채움

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 웨딩 박람회장. 이한의 부스 옆에 태오가 새 간판을 세운다. "이혼 전문"을 내리고 "재결합·가족관계 회복 전문"으로 바꾼 간판.
- 마지막 대사 한 줄:
  → "이번엔 내가 먼저 계약서 쓸게. 평생 갱신 안 되는 걸로."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요?
  → 이한은 '완벽한 결혼식'이 아니어도 사랑할 수 있다는 걸 배운다. 태오는 '끝나지 않는 관계'가 있다는 걸 처음으로 믿는다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요?
  → 이한은 자신이 기획한 웨딩이 태오가 예전에 이혼 소송을 맡았던 의뢰인의 재혼이었다는 걸 알고 뒤통수 맞은 기분을 느낀다. 태오는 그 사실을 알면서도 미리 말하지 않았다.
- 둘이 가장 많이 상처 주는 장면은?
  → 이한: "당신은 사랑을 안 믿는 사람이라 나까지 의심하게 만들어." 태오는 반박하지 못하고 사무실을 정리해 건물을 나간다.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는?
  → 결말이 '나란히 간판을 세운다'라면, 출발은 '한 건물, 다른 층에서 서로의 존재를 못마땅해한다'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 태오가 간판을 "재결합 전문"으로 바꿈 | 태오가 "이혼도 화해로 끝나는 케이스가 있긴 하다"고 무심코 흘리는 대사 | 1권 20화 |
| "평생 갱신 안 되는 걸로" 대사 | 이한이 계약서 초안마다 '갱신 조항'을 두는 습관을 반복해서 보여줌 | 1권 5화, 2권 25화 |
| 부모 유품 반지를 이한에게 줌 | 태오가 반지를 무의식적으로 만지작거리는 습관, 이한이 그걸 눈치채고 묻지 않고 넘어가는 장면 | 1권 9화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 같은 건물, 다른 층. 한쪽 로비엔 웨딩드레스 샘플이, 다른 쪽엔 이혼 서류 파일함이 나란히 엘리베이터를 기다린다.
- **떠오른 대사:** "저는 사람을 이어 주는 일을 해요." / "저는 정리해 드리는 일을 하고요. 둘 다 필요한 일이죠, 그쪽이 인정하기 싫으시겠지만."
- **떠오른 설정·관계:** 웨딩플래너와 이혼 전문 변호사가 한 건물에 사무실을 나눠 쓰게 됨. 공용 로비, 공용 회의실을 두고 부딪힌다.
- **어디서 왔나:** "결혼식장 옆 건물에 이혼 상담소가 있으면 어떨까" 하는 실없는 생각.
- **가장 강하게 느낀 감정 하나:** 짜릿함 (정반대 신념을 가진 두 사람이 부딪히는 데서 오는 긴장)

## 2단계 · 로그라인과 트로프

**공식:** '완벽한 결혼식'만이 완벽한 사랑이라 믿는 웨딩플래너 이한이, 사랑엔 유통기한이 있다고 믿는 이혼 전문 변호사 태오를 같은 건물에서 매일 마주치지만, 서로의 직업이 서로의 신념을 부정한다는 이유로 부딪히면서도 자꾸 끌린다.

- **로그라인:** 결혼을 만드는 여자와 이혼을 정리하는 남자가 한 건물을 나눠 쓰며, 서로가 서로의 신념을 무너뜨릴까 봐 두려워하면서도 사랑에 빠진다.
- **작품 가제목:** 결혼과 이혼 사이
- **장르:** 현대 로맨스
- **배경:** 오피스텔 건물 (웨딩플래너 사무실 3층, 로펌 5층, 1층 공용 카페)
- **분위기:** 티키타카 코미디 → 후반 잔잔·먹먹
- **핵심 트로프(최대 3개):** 원수에서 연인, 직업적 신념 대비, 비밀(겹치는 의뢰인)

## 3단계 · 인물 카드

| 항목 | 주인공 A (이한) | 주인공 B (강태오) |
| --- | --- | --- |
| 이름·나이·직업 | 이한, 30세, 웨딩플래너('맺음' 대표) | 강태오, 32세, 이혼 전문 변호사 |
| 한마디 인상 | 웃는 얼굴로 밀어붙이는 사람 | 표정 없이 할 말만 하는 사람 |
| 결핍·상처 | 3년 전 파혼당함. 그 사실을 아무에게도 말하지 않음 | 어릴 때 부모의 지리멸렬한 이혼을 겪고 혼자 방치됨 |
| 겉으로 원하는 것 | 모든 웨딩을 '완벽하게' 성사시키는 것 | 감정 개입 없이 깔끔하게 사건을 종결하는 것 |
| 사실 필요한 것 | 불완전해도 사랑받을 수 있다는 확신 | 누군가 끝까지 곁에 남아 있을 거라는 믿음 |
| 연애를 막는 내면의 벽 | '내가 완벽해야 아무도 안 떠난다' | '사랑은 결국 서류 한 장으로 끝난다' |
| 매력 포인트 | 지치지 않고 디테일을 챙기는 다정함 | 상대 말을 끝까지 들어주는 차분함, 가끔 툭 던지는 다정함 |
| 말버릇·습관 | "이 정도는 기본이에요" / 계약서 모서리를 접는 버릇 | "그래서, 원하는 결과가 뭡니까" / 부모 유품 반지를 무의식적으로 만지작거림 |
| 상대에게만 보여 주는 모습 | 태오 앞에서만 계획에 없던 말을 즉흥으로 한다 | 이한 앞에서만 업무 말투를 풀고 웃는다 |

> A는 '완벽해야 사랑받는다'고 믿고, B는 '사랑은 끝난다'고 믿는다. 둘 다 틀렸다는 걸 서로를 통해 알게 된다.

## 4단계 · 관계와 갈등

- **끌리는 이유:** 이한은 태오의 정직한 냉소가 오히려 편안하다(꾸미지 않아도 되니까). 태오는 이한의 지치지 않는 다정함에 끌리지만 그게 언젠가 꺼질까 봐 두렵다.
- **이어질 수 없는 이유 – 외적 갈등:** 같은 건물 임대 계약 문제로 로비 사용을 두고 신경전. 두 사람의 의뢰인이 겹치는 사건(결혼 준비 중이던 커플이 파혼 소송으로 넘어옴)이 터진다.
- **이어질 수 없는 이유 – 내적 갈등:** 이한은 파혼 경험을 숨기려 완벽주의로 도피하고, 태오는 '사랑은 유통기한이 있다'는 신념을 놓지 못한다.
- **두 사람의 힘의 균형:** 초반엔 이한이 씩씩하고 주도적, 태오는 방어적으로 거리를 둔다. 위기 이후에는 태오가 먼저 무너지고 이한에게 다가간다.
- **둘만의 상징물:** 계약서 서명란에 이한이 몰래 그려 넣는 하트 모양 낙서. 1층 공용 카페의 늘 같은 자리.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 씁쓸함 뒤에 오는 안도감 — "깨진 것도 다시 이어 붙일 수 있구나."

## 5단계 · 회차 구성

- **예상 분량:** 총 75화 (3권)
- **연재 플랫폼(예정):** 미정

| 구간 | 회차 | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 결혼식 당일, 두 사람의 못 다한 신혼여행 이야기 |  |
| 결말 | 3권 · 69~75화 | 나란히 간판을 세우는 장면, 이한이 자신의 파혼 이야기를 처음으로 태오에게 꺼낸다 |  |
| 절정 | 3권 · 59~68화 | 태오가 자신의 반지를 이한에게 건네며 "끝나지 않는 계약을 믿어 보겠다"고 말함 |  |
| 위기 | 2권 후반~3권 초 · 39~58화 | 겹치는 의뢰인 사건 폭로, 이한의 절연 선언, 태오가 사무실을 뺀다 |  |
| 중간 전환 | 2권 중반 · 31~38화 | 공용 카페에서 첫 키스, 서로의 상처(파혼/부모 이혼)를 처음 털어놓음 |  |
| 전개 | 1권 후반~2권 초 · 13~30화 | 로비 신경전이 티키타카로 바뀌고, 서로의 의뢰인 상담을 몰래 도와주기 시작함 |  |
| 계기 | 1권 · 8~12화 | 건물 관리실의 실수로 두 사무실이 공용 회의실을 매주 같은 시간에 예약당함 |  |
| 도입 | 1권 · 1~7화 | 이한의 완벽한 웨딩 상담 vs 태오의 건조한 이혼 상담을 교차로 보여줌, 엘리베이터에서 첫 충돌 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 태오가 이한 몰래 파혼 기록을 찾아보고도 모르는 척해 주는 장면
- [ ] 이한이 태오의 의뢰인(이혼 앞둔 부부)에게 자기도 모르게 위로를 건네는 장면
- [ ] 두 사람이 같은 결혼식에서 정반대 이유로 눈물을 참는 장면 (이한은 감동, 태오는 예전 기억)

**회차 끝 훅 아이디어**

- 1화 끝: 이한이 태오의 사무실 명패를 잘못 보고 "이혼 축하드립니다"라고 말해버림
- 38화 끝: 태오가 이한의 예전 파혼 기사 스크랩을 서랍에서 발견함
- 58화 끝: 이한이 태오의 사무실 문 앞에 계약서(갱신 조항 없는) 한 장만 두고 감
