# 로맨스 글감 노트 — 소극장 조명감독

Sep 24, 2026 · 자동 생성 (템플릿 기반)

> [로맨스_글감_노트_템플릿.md](로맨스_글감_노트_템플릿.md)을 복제해 채운 글감 노트예요. 매주 다른 글감으로 이 노트를 하나씩 더 만들어 쌓아 갈 예정이에요.

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 재개설 첫날 밤, 소극장 객석 맨 뒷줄. 진하가 새로 짠 조명 큐를 무진이 처음으로 지켜본다.
- 마지막 대사 한 줄:
  → "이번엔 안 꺼트릴게요. 조명도, 우리도."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요?
  → 진하는 '완벽한 큐'에 집착하던 신입에서, 정전 같은 사고도 받아들이는 조명감독이 된다. 무진은 극장을 숫자로만 보던 대표에서, 다시 무대에 남기로 결정한 연출가가 된다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요?
  → 극장이 결국 매각 절차에 들어가고, 진하가 짠 마지막 공연 큐가 통째로 취소된다. 둘은 같은 편이 아니었다는 오해가 정점을 찍는다.
- 둘이 가장 많이 상처 주는 장면은?
  → 무진이 "어차피 취미로 하는 일 아니었냐"고 던진 말에, 진하가 자신의 유일한 진로였던 조명 일을 그만두겠다고 선언하는 장면.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는?
  → 결말이 '같은 무대를 함께 본다'라면, 출발은 '서로를 극장의 걸림돌로 여긴다'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 정전 상황에서도 침착한 진하 | 1화, 첫 리허설에서 조명이 나가자 당황해 우는 진하 | 1화 |
| "조명도, 우리도" 대사 | 3화, 무진이 무심코 "네 큐는 안 꺼지네"라고 칭찬 | 3화 |
| 무진이 극장에 남기로 결정 | 초반, 무진이 몰래 옛 배우 시절 티켓을 서랍에 숨겨 둔 장면 | 5화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 정전으로 암전된 소극장 무대, 핸드폰 손전등 두 개가 서로의 얼굴만 비춘다.
- **떠오른 대사:** "당신 조명이 제일 별로였어요. 근데 그 별로인 조명 덕분에 제가 안 울고 버텼어요."
- **떠오른 설정·관계:** 폐관 위기에 몰린 소극장의 까칠한 대표 겸 연출가와, 그 극장에 인턴으로 들어온 신입 조명감독.
- **어디서 왔나:** 오래된 동네 소극장 앞을 지나다가 '이번 공연이 마지막일지도 모른다'는 안내문을 본 것에서.
- **가장 강하게 느낀 감정 하나:** 애탐 (지켜 주고 싶은데 방법을 모르는 마음)

## 2단계 · 로그라인과 트로프

- **로그라인:** 폐관 직전인 소극장에 조명감독으로 들어온 신입 진하가 까칠한 대표 겸 연출가 무진을 만나지만, 극장을 팔아야 하는 그의 사정과 무대를 지키고 싶은 그녀의 마음이 부딪히는 가운데, 둘은 마지막 공연의 조명 하나에 서로를 믿어 볼 수 있을까?
- **작품 가제목:** 《암전 뒤에 남는 빛》
- **장르:** 현대 로맨스
- **배경:** 망원동 골목의 오십 석짜리 소극장
- **분위기:** 잔잔 · 힐링, 중반 이후 살짝 피폐
- **핵심 트로프(최대 3개):** 원수(까칠한 상사)에서 연인으로 · 재회 아님(첫 만남) · 죄책감·돌봄

**자주 쓰는 트로프 예시**

| --- | --- | --- |
| 인턴으로 입사 | 상사·부하 | 짝사랑에서 시작해 쌍방으로 |
| 같은 목표(극장 살리기) | 카리스마 × 다정 | 죄책감·돌봄 |

## 3단계 · 인물 카드

| 항목 | 주인공 A (진하) | 주인공 B (무진) |
| --- | --- | --- |
| 이름·나이·직업 | 오진하, 26세, 소극장 인턴 조명감독 | 백무진, 34세, 소극장 대표 겸 연출가 |
| 한마디 인상 (별명처럼) | '큐시트를 세 번 확인하는 애' | '숫자로만 말하는 대표' |
| 결핍·상처 | 대학 졸업 공연 도중 조명 사고로 무대를 망친 뒤, 자신이 하는 일에 확신이 없다 | 배우였던 과거, 부상으로 무대를 떠난 뒤 극장을 물려받았지만 무대와 거리를 두려 한다 |
| 겉으로 원하는 것 | 이번 공연만은 실수 없이 끝내는 것 | 극장을 정리하고 깔끔하게 손 떼는 것 |
| 사실 필요한 것 | 실수해도 괜찮다는 확인 | 다시 무대를 사랑해도 된다는 허락 |
| 연애를 막는 내면의 벽 | '나는 또 망칠 것이다'라는 두려움 | '무대에 마음을 주면 또 잃는다'는 회피 |
| 매력 포인트 (독자가 반하는 부분) | 겁내면서도 끝까지 큐시트를 붙잡는 고집 | 퉁명스럽지만 배우들 동선 하나하나를 기억하는 다정함 |
| 말버릇·습관 | 긴장하면 큐시트 모서리를 접는다 | 대답 대신 "그래서 결론이 뭔데"라고 되묻는다 |
| 상대에게만 보여 주는 모습 | 무진 앞에서만 실수를 먼저 고백한다 | 진하 앞에서만 옛날에 배우였다는 이야기를 꺼낸다 |

> 짧은 예: 진하는 '완벽해야 다시 인정받는다'고 믿고, 무진은 '틀려도 무대는 계속된다'는 걸 몸으로 아는 사람. 이러면 사건이 없어도 둘 사이에 긴장이 생겨요.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 진하에게 무진은 처음으로 "네 잘못이 아니다"라고 말해 준 사람이고, 무진에게 진하는 처음으로 극장 밖 미래가 아니라 지금 이 무대를 보게 만든 사람.
- **이어질 수 없는 이유 – 외적 갈등:** 극장 매각 계약, 상사와 인턴이라는 위치.
- **이어질 수 없는 이유 – 내적 갈등:** 진하의 실패에 대한 두려움, 무진의 무대 회피.
- **두 사람의 힘의 균형:** 처음엔 무진이 결정권을 다 쥐고 있지만, 2권 후반 극장을 살릴 방법을 진하가 먼저 찾아내면서 균형이 뒤집힌다.
- **둘만의 상징물:** 손전등 두 개, 접힌 자국이 남은 큐시트.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 뭉근하게 안심되는 기분.

## 5단계 · 회차 구성

- **예상 분량:** 총 75화 (3권 기준)
- **연재 플랫폼(예정):** 미정

| 구간 | 회차 (3권·약 75화 기준) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 재개관 첫 공연 뒤풀이 | 손전등 두 개로 커튼콜 재연 |
| 결말 | 3권 · 69~75화 | 재개관, 함께 지켜보는 무대 | "조명도, 우리도" 대사 |
| 절정 | 3권 · 59~68화 | 무진이 극장 매각을 철회하고 진하 앞에서 무대에 다시 서기로 결심 | |
| 위기 | 2권 후반~3권 초 · 39~58화 | 매각 확정, "취미 아니었냐" 발언으로 크게 다툼 | |
| 중간 전환 | 2권 중반 · 31~38화 | 정전 사고 함께 수습하며 첫 고백 직전까지 | |
| 전개 | 1권 후반~2권 초 · 13~30화 | 밤샘 리허설, 서로의 상처를 조금씩 알게 됨 | |
| 계기 | 1권 · 8~12화 | 극장 매각설이 돌고, 진하가 마지막 공연을 지켜 내자고 제안 | |
| 도입 | 1권 · 1~7화 | 첫 리허설에서 조명 사고, 무진에게 혼나는 진하 | |

**꼭 넣고 싶은 장면 목록**

- [ ] 정전 속 손전등 두 개로 서로를 비추는 장면
- [ ] 무진이 옛 배우 시절 티켓을 몰래 꺼내 보는 장면
- [ ] 진하가 큐시트 접는 습관을 무진이 알아채는 장면

**회차 끝 훅(다음 화를 누르게 만드는 마지막 장면) 아이디어**

- 12화 끝: 매각 서류에 도장을 찍으려던 무진 앞에, 진하가 마지막 공연 기획안을 내민다.
