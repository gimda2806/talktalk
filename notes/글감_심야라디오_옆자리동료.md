## 1단계 · 번뜩임 기록

- **떠오른 장면:** 심야 라디오 작가가 방송 전 마지막으로 사연 하나를 고르다가, 매일 같은 시간에 오는 익명의 사연이 옆자리 동료의 말버릇과 똑같다는 걸 눈치챈다.
- **떠오른 대사:** "저 사람, 자기가 라디오에 나온다는 거 알까요?" / "…알아요. 제가 보낸 거니까요."
- **떠오른 설정·관계:** 같은 사무실에서 매일 얼굴 보는 동료가, 밤에는 얼굴 없는 사연자로 서로에게 속마음을 고백하고 있었다.
- **어디서 왔나:** 라디오 사연을 읽다가 "이거 꼭 내 얘기 같다"는 후기를 보고 떠올림.
- **가장 강하게 느낀 감정 하나:** 그리움과 들킬까 봐 조마조마한 설렘.

## 2단계 · 로그라인과 트로프

**로그라인:** 낮에는 냉정한 라디오 구성작가로 사는 이수련이, 밤마다 얼굴 없는 사연으로 위로를 주고받던 익명의 청취자가 옆자리 신입 PD 강지오라는 걸 알게 되지만, 방송에서 그 정체를 밝히는 순간 서로의 가장 여린 부분이 사무실 전체에 공개된다는 사실 때문에 망설인다.

- **작품 가제목:** 《12시의 그 사람에게》
- **장르:** 현대 로맨스
- **배경:** 지역 라디오 방송국, 심야 시사·음악 프로그램
- **분위기:** 잔잔 · 달달 · 살짝 아련
- **핵심 트로프(최대 3개):** 비밀 정체(익명 사연자), 짝사랑·쌍방 오해, 동료에서 연인으로

## 3단계 · 인물 카드

| 항목 | 주인공 A (이수련, 29) | 주인공 B (강지오, 31) |
| --- | --- | --- |
| 이름·나이·직업 | 이수련, 29, 라디오 구성작가 7년 차 | 강지오, 31, 신입 PD (경력 전향) |
| 한마디 인상 | 방송국에서 제일 빈틈없는 사람 | 말수 적고 다정한 새 PD |
| 결핍·상처 | 예전 연애에서 "네 감정은 너무 무겁다"는 말을 듣고 속마음을 숨기는 버릇이 생김 | 전 직장에서 번아웃으로 퇴사, 자기 얘기를 꺼내는 게 서툴다 |
| 겉으로 원하는 것 | 완벽한 큐시트, 흔들리지 않는 하루 | 조용히 자리 잡고 실수 안 하기 |
| 사실 필요한 것 | 판단받지 않고 솔직해질 수 있는 자리 | 자기 얘기를 들어 줄 한 사람 |
| 연애를 막는 내면의 벽 | "감정을 보이면 부담스러워한다"는 믿음 | 다시 마음을 내줬다가 소진될까 봐 두려움 |
| 매력 포인트 | 사연 하나를 고를 때도 진심으로 듣는 태도 | 서투르지만 늘 한 박자 먼저 챙기는 배려 |
| 말버릇·습관 | 사연 읽을 때만 존댓말이 부드러워짐 | 대답 전에 꼭 3초쯤 뜸을 들인다 |
| 상대에게만 보여 주는 모습 | 사연(밤의 정체)으로는 눈물 이야기를 쓴다 | 사연으로는 "오늘도 잘 버텼다"는 인사를 보낸다 |

> 낮의 수련과 지오는 존댓말로 딱딱하게 업무만 나누지만, 밤의 두 사람은 서로의 이름도 모른 채 가장 여린 얘기를 나눈다. 그 간극이 이 글감의 엔진이다.

## 4단계 · 관계와 갈등

- **끌리는 이유:** 낮의 지오가 아니라, 밤에 도착하는 사연 속 목소리에 먼저 반한다. 얼굴을 몰라서 오히려 솔직할 수 있었다.
- **이어질 수 없는 이유 – 외적 갈등:** 사내 연애 금지까지는 아니지만, 방송에서 "사연 주인공이 옆자리 동료였다"가 밝혀지면 팀 전체에 소문이 돈다. 곧 있을 개편 심사에서 "사적 관계로 공사 구분 못 한다"는 평가를 받을 위험.
- **이어질 수 없는 이유 – 내적 갈등:** 수련은 "밤의 나"를 들키면 낮의 완벽한 이미지가 깨질까 두렵고, 지오는 "진짜 나"를 보여 준 상대가 매일 보는 동료라는 걸 알면 수련이 부담스러워할까 봐 먼저 말 못 한다.
- **두 사람의 힘의 균형:** 처음엔 수련이 선배·고정 작가로 더 많이 가졌지만, 사연을 통해 지오가 먼저 수련의 여린 부분을 알게 되면서 균형이 뒤집힌다.
- **둘만의 상징물:** 매일 밤 12시에 뜨는 사연 접수 알림음, 그리고 지오가 매번 마지막 줄에 붙이는 한 마디 "오늘도 잘 버텼어요."
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 아무도 모르게 나를 응원해 준 사람이 실은 내내 가까이 있었다는 온기.

## 5단계 · 회차 구성 (하이라이트만 먼저)

- **예상 분량:** 총 40화 내외 (미니 연재 기준)
- **연재 플랫폼(예정):** 미정

| 구간 | 회차(가안) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 도입 | 1~5화 | 낮의 냉랭한 두 사람 + 밤의 사연 교환 병렬로 보여 주기 |  |
| 계기 | 6~9화 | 수련이 사연자의 말버릇에서 지오를 의심하기 시작 |  |
| 전개 | 10~22화 | 확신을 감춘 채 낮에도 조금씩 가까워짐, 사연은 점점 서로를 향한 고백에 가까워짐 |  |
| 중간 전환 | 23~26화 | 생방송 사고로 사연이 실수로 조기 송출, 지오가 "그거 제가 쓴 거예요"라고 밝힘 |  |
| 위기 | 27~34화 | 개편 심사 압박 + 소문, 수련이 "밤의 나"를 지키려 지오를 밀어냄 |  |
| 절정 | 35~38화 | 마지막 방송에서 수련이 직접 사연을 읽으며 답장한다 |  |
| 결말 | 39~40화 | 이름을 걸고 다시 시작하는 두 사람 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 수련이 처음으로 자기 이름을 걸고 사연에 답장을 쓰는 장면
- [ ] 두 사람이 방송국 옥상에서 "12시의 그 사람"이 서로였다는 걸 인정하는 장면
