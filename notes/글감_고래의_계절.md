# 글감 노트 · 고래의 계절 (가제)

Sep 24, 2026 · 로맨스_글감_노트_템플릿.md 복제본

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 개장 전 텅 빈 아쿠아리움 수조 앞. 하늘과 이주가 나란히 앉아, 이제 완치되어 방류를 앞둔 벨루가 '루나'에게 마지막으로 휘파람 신호를 불어 준다.
- 마지막 대사 한 줄: "이제 저 신호, 너 말고 아무한테도 안 불 거예요."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요? 하늘은 '완벽하게 지켜야만 사랑할 자격이 있다'는 믿음을 버리고 실수해도 곁에 남는 법을 배운다. 이주는 어디에도 정착하지 못하던 발걸음을 처음으로 한곳에 붙잡아 둔다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요? 하늘의 판단 실수로 루나의 상태가 갑자기 악화되고, 이주가 책임을 대신 떠안으며 본사 징계를 받아 해외 지사로 발령난다. 하늘은 그 사실을 나중에야 알고 자책한다.
- 둘이 가장 많이 상처 주는 장면은? 하늘이 "나 지켜준답시고 마음대로 결정하지 마요, 나 그런 거 바란 적 없어요"라며 이주의 자기희생을 밀어내는 장면.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는? 결말이 '같은 휘파람 신호를 둘만의 것으로 나눠 갖는다'라면, 출발은 '서로 다른 방식으로 같은 고래를 부르며 신호가 겹쳐 루나가 오히려 혼란스러워하는' 충돌 관계.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 둘만의 휘파람 신호 | 1권 초반, 서로 다른 음정으로 루나를 불러 헷갈리게 만드는 다툼 | 2화 |
| "이제 저 신호, 너 말고 아무한테도 안 불 거예요" | 1권 중반, 하늘이 신호를 아무한테나 가르쳐 주지 않는다는 원칙을 세우는 장면 | 10화 |
| 이주가 정착을 선택하는 결말 | 1권, 이주가 "3개월짜리 파견"이라고 스스로 선을 긋는 장면 | 1화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 야간 개장이 끝난 텅 빈 아쿠아리움, 수조 유리에 이마를 맞대고 서 있는 벨루가와 사육사 한 명, 그 뒤로 다가오는 낯선 발소리
- **떠오른 대사:** "그 휘파람, 어디서 배운 거예요? 저만 아는 신호인데." / "당신이 5년 전에, 저한테 가르쳐 줬잖아요."
- **떠오른 설정·관계:** 부상당한 벨루가를 치료하러 해외에서 파견 온 해양생물학자가, 대학 시절 실습에서 잠깐 스쳤던 사육사와 같은 개체를 사이에 두고 매일 부딪힘
- **어디서 왔나:** 다큐멘터리에서 사육사가 특정 휘파람 음정으로만 반응하는 벨루가를 보고, 그 소리가 사람 사이의 암호처럼 느껴졌던 경험
- **가장 강하게 느낀 감정 하나:** 그리움 (그리고 낯섦 속에 섞인 반가움)

> 씨앗은 어떤 모양이든 심어 두면 돼요. 감정 한 단어가 나중에 이야기의 나침반이 돼요.

## 2단계 · 로그라인과 트로프

**공식:** 부상당한 벨루가를 지키려 원칙을 목숨처럼 여기는(상황) 아쿠아리움 사육사 오하늘(주인공 A)이 3개월 파견을 선 그어 둔 해양생물학자 강이주(주인공 B)를 만나지만, 5년 전 실습생 시절 서로가 서로를 잊지 못하게 만든 신호 하나를 여전히 기억하고 있기 때문에(걸림돌) 이번에도 곁에 남지 않을 사람에게 곁을 내줘도 되는지(질문/긴장) 한다.

- **로그라인:** 위 문장 그대로
- **작품 가제목:** 고래의 계절
- **장르:** 현대 로맨스
- **배경:** 국립 아쿠아리움, 해양 동물 재활 센터
- **분위기:** 잔잔 / 힐링 (야간 수조의 푸른 조명과 물소리 중심)
- **핵심 트로프(최대 3개):** 재회(첫 실습 인연), 강제로 같은 당직을 서게 됨, 돌봄·죄책감

**자주 쓰는 트로프 예시**

| 관계 시작 | 관계 구도 | 감정 장치 |
| --- | --- | --- |
| 계약 연애·계약 결혼 | 혐관에서 연인으로 | 짝사랑·쌍방 오해 |
| 재회(구연인·첫사랑) ✅ | 친구에서 연인으로 | 비밀 연애 |
| 같이 살게 됨(동거) | 상사·부하, 선배·후배 ✅(파견 전문가·현장 사육사) | 질투·삼각관계 |
| 가짜 연인 연기 | 라이벌·원수 | 기억상실·시한부 |
| 잡지 못한 이별 후 재회 | 카리스마 × 다정 | 죄책감·돌봄 ✅ |

## 3단계 · 인물 카드

| 항목 | 주인공 A (오하늘) | 주인공 B (강이주) |
| --- | --- | --- |
| 이름·나이·직업 | 오하늘, 28세, 국립 아쿠아리움 벨루가 담당 사육사 | 강이주, 31세, 해외 재활센터 소속 해양생물학자·수의사 |
| 한마디 인상 (별명처럼) | '매뉴얼보다 더한 애' | '왔다가 사라지는 사람' |
| 결핍·상처 | 실습생 시절 자기 실수로 담당하던 물고기를 잃은 뒤 완벽한 절차만이 생명을 지킨다고 믿게 됨 | 어디에도 오래 머문 적 없이 파견지만 옮겨 다니며, 정착하면 또 잃을까 봐 미리 거리를 둠 |
| 겉으로 원하는 것 | 루나를 원칙대로, 실수 없이 완치시키는 것 | 3개월 안에 치료를 끝내고 다음 파견지로 떠나는 것 |
| 사실 필요한 것 | 완벽하지 않아도 곁에 있어도 된다는 확신 | 떠나지 않아도 될 이유 하나 |
| 연애를 막는 내면의 벽 | 마음을 주면 판단이 흐려져 또 누군가(무언가)를 잃을 거라는 두려움 | 정착은 곧 언젠가의 이별을 예약하는 일이라는 믿음 |
| 매력 포인트 (독자가 반하는 부분) | 매뉴얼에 없는 상황에서도 루나의 미세한 신호를 가장 먼저 알아채는 관찰력 | 정형화된 치료법을 벗어나 동물 개체마다 다른 방식으로 접근하는 유연함 |
| 말버릇·습관 | 당직 일지에 그날 루나의 기분을 한 문장으로 요약해 적는다 | 새 파견지에 도착하면 짐을 절반만 푼다 |
| 상대에게만 보여 주는 모습 | 루나 앞에서만 부르는, 아무에게도 가르쳐 주지 않은 휘파람 신호를 알려 준다 | 이번엔 짐을 다 풀어 옷장 서랍까지 채운다 |

> 하늘은 '실수하면 곁에 있을 자격이 없다'고 믿고, 이주는 '실수해도 남는 게 진짜'라고 몸으로 보여 주는 사람. 이러면 사건이 없어도 둘 사이에 긴장이 생겨요.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 하늘이 홀로 지켜 온 루나와의 신호를, 이주가 5년 전부터 이미 알고 있었다는 사실이 두 사람을 다시 연결한다. 서로만 아는 언어가 있다는 감각.
- **이어질 수 없는 이유 – 외적 갈등:** 이주는 3개월 뒤 계약이 끝나면 다음 파견지로 옮겨야 하는 임시직이고, 하늘은 이 아쿠아리움을 떠날 수 없는 정규직 사육사다.
- **이어질 수 없는 이유 – 내적 갈등:** 하늘은 마음을 주면 판단력이 흐려질까 두려워하고, 이주는 정착하면 결국 또 이별할 거라 믿는다.
- **두 사람의 힘의 균형:** 초반엔 현장 경험과 결정권에서 하늘이 앞서지만, 루나의 상태가 악화되며 전문 치료 지식을 가진 이주 쪽으로 균형이 넘어간다.
- **둘만의 상징물:** 루나만 반응하는 특정 음정의 휘파람 신호
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 완벽하지 않아도, 떠났다 돌아와도 괜찮다는 잔잔한 안도감

## 5단계 · 회차 구성

- **예상 분량:** 총 60화 (2권 기준)
- **연재 플랫폼(예정):** 미정 (카카오페이지/리디 등 검토)

| 외전 | (선택) | 루나 방류 1년 뒤, 두 사람이 함께 방류 해역을 찾아가는 날 |  |
| 결말 | 2권 · 55~60화 | 루나 방류식, 둘만의 신호를 함께 나눠 갖기로 함 |  |
| 절정 | 2권 · 47~54화 | 이주의 징계와 발령 사실이 밝혀지고, 하늘이 그를 붙잡으러 감 |  |
| 위기 | 1권 후반~2권 초 · 31~46화 | 루나 상태 악화, 이주의 자기희생, 두 사람이 서로를 밀어냄 |  |
| 중간 전환 | 1권 후반 · 25~30화 | 이주가 5년 전 자신이 신호를 가르쳐 줬다고 고백하는 장면 |  |
| 전개 | 1권 · 10~24화 | 같은 당직을 서며 서로의 방식에 부딪히다 조금씩 맞춰가는 밀당 |  |
| 계기 | 1권 · 4~9화 | 루나의 부상으로 두 사람이 강제로 같은 당직 파트너가 됨 |  |
| 도입 | 1권 · 1~3화 | 야간 수조 앞, 낯선 휘파람 신호로 다시 마주친 첫 장면 |  |

**회차 끝 훅(다음 화를 누르게 만드는 마지막 장면) 아이디어**

- 1화 끝: 낯선 사람이 부는 휘파람에 루나가 반응하고, 하늘이 "그거 제 신호인데요"라고 돌아보는 순간
- 30화 끝: 이주가 "그 신호, 제가 가르쳐 드렸잖아요"라며 5년 전 실습 사진을 꺼내는 순간
