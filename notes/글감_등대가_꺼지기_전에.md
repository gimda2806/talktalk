# 글감 노트 · 등대가 꺼지기 전에

Sep 24, 2026 · 자동 생성 (매시간 새 글감 채우기)

> `로맨스_글감_노트_템플릿.md`를 복제해서 채운 글감 노트예요. 템플릿 사용법·비유 설명은 생략하고 실제 내용만 채웠어요.

## 내 방식 · 끝에서 거꾸로 설계하기

**2권 (도착지, 45화 기준 → 3권 표의 2/3 환산)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 철거가 보류된 등대 꼭대기. 소이가 새로 켠 등대 불빛 아래, 재하가 소이의 카메라 셔터를 대신 눌러 준다.
- 마지막 대사 한 줄: "이제 안 꺼져요. 제가 매일 켤 거니까." — "그럼 저도 매일 와야겠네요."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요? 재하는 "곁에 있으면 다치게 한다"는 죄책감을 내려놓고 사람을 다시 들이고, 소이는 무언가를 기록만 하던 사람에서 직접 지키는 사람이 된다.

**1권 후반 (가장 멀어진 지점)**

- 소이의 보고서 초안이 "철거 불가피"로 결론 나고, 재하가 그 사실을 먼저 알게 되며 소이를 말없이 떠나보낸다.
- 가장 많이 상처 주는 장면: 재하가 "처음부터 여긴 어차피 없어질 곳이었습니다"라며 소이가 내밀었던 손을 놓는다.

**1권 초반 (출발지)**

- 결말이 '매일 불을 켜며 함께한다'라면, 출발은 '각자 아무도 들이지 않는 방식으로 하루를 버틴다'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 소이가 셔터를 재하에게 맡긴다 (신뢰의 상징) | 소이는 카메라를 남에게 절대 안 맡기는 습관이 있다고 1화에서 보여주기 | 1화 |
| "이제 안 꺼져요" 대사 | 등대 전구가 낡아서 자주 꺼진다는 설정, 재하가 밤마다 확인하는 루틴 | 3화 |
| 무선기를 함께 고치는 장면 | 태풍 첫날 무선기가 고장 나 육지와 연락이 끊긴다 | 6화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 태풍으로 배가 끊긴 섬, 마지막 등대지기 오두막 문을 두드리는 낯선 손님
- **떠오른 대사:** "저기요, 저 여기 갇힌 거 맞죠?" / "네. 그리고 저도요, 사실은."
- **떠오른 설정·관계:** 사람을 피해 섬에 들어온 전직 항해사 등대지기와, 등대 철거 여부를 조사하러 온 건축가가 태풍에 발이 묶여 한 지붕 아래 사흘을 보낸다.
- **어디서 왔나:** 무인등대 철거 관련 기사 + 태풍에 발이 묶인 여행 브이로그
- **가장 강하게 느낀 감정 하나:** 그리움과 안도가 섞인, '멈춰선 시간의 편안함'

> 씨앗 메모: 등대는 재하에게는 '숨는 곳', 소이에게는 '기록해서 붙잡아야 할 것'. 같은 공간이 두 사람에게 정반대 의미라는 게 이야기의 엔진.

## 2단계 · 로그라인과 트로프

**로그라인:** 사고로 동료를 잃고 섬 등대에 스스로를 가둔 전직 항해사 도재하가, 등대 철거 여부를 조사하러 온 건축가 한소이를 만나지만, 태풍에 발이 묶여 함께 지내야 하는 사흘 동안 서로가 도망쳐 온 이유를 마주하게 된다.

- **작품 가제목:** 등대가 꺼지기 전에
- **장르:** 현대 로맨스
- **배경:** 육지에서 배로 40분 거리, 유인 등대가 있는 외딴 섬
- **분위기:** 잔잔 · 힐링 (중반부 애틋함)
- **핵심 트로프(최대 3개):** 한정된 공간(고립·한 지붕), 돌봄·죄책감, 철거 전 마지막 시간(공간판 시한부)

| 말버릇·습관 | "괜찮습니다"로 거리를 둔다 | 마음이 흔들릴 때마다 카메라 셔터를 누른다 |
| 상대에게만 보여 주는 모습 | 밤바다를 보며 잃은 동료 이야기를 털어놓는다 | 재하가 고친 부품 하나하나에 아이처럼 좋아한다 |

## 4단계 · 관계와 갈등

- **끌리는 이유:** 둘 다 '무언가를 잃은 자리를 계속 지키는 사람'이라 서로를 한눈에 알아본다.
- **외적 갈등:** 소이의 보고서가 등대 철거 여부를 결정한다. 철거가 확정되면 소이는 떠나야 하고 재하는 지낼 곳을 잃는다.
- **내적 갈등:** 재하는 "곁에 있으면 다치게 한다"는 죄책감으로 다가오는 소이를 밀어내고, 소이는 "이번에도 지키지 못하면 어쩌나" 하는 두려움으로 마음을 미룬다.
- **두 사람의 힘의 균형:** 초반엔 소이가 등대(=재하의 삶터)의 운명을 쥔 '조사관'으로 우위. 후반으로 갈수록 재하가 먼저 자기 이야기를 여는 쪽으로 뒤집힌다.
- **둘만의 상징물:** 태풍 첫날 고장 난 무선기(함께 고치는 것), 등대 불이 다시 켜지는 순간
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 잃은 것도 다시 불을 켤 수 있다는 잔잔한 희망

## 5단계 · 회차 구성

- **예상 분량:** 총 45화 (2권, 3권 75화 기준 표에 2/3 환산)
- **연재 플랫폼(예정):** 미정 (카카오페이지 / 리디 후보)

| 구간 | 회차 (2권·45화 환산) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 소이가 매년 태풍철마다 섬에 오는 후일담 |  |
| 결말 | 41~45화 | 등대 존치 확정, 두 사람이 매일 불을 켜는 일상 |  |
| 절정 | 35~40화 | 재하가 사고의 진실을 소이에게 처음으로 말한다 |  |
| 위기 | 23~34화 | 철거 결정 통보, 재하가 먼저 소이를 밀어내고 소이가 섬을 떠난다 |  |
| 중간 전환 | 19~22화 | 태풍이 그친 뒤 무선기를 함께 고치며 첫 마음 인정 |  |
| 전개 | 8~18화 | 태풍에 갇힌 사흘, 서로의 루틴에 스며들며 설렘 포인트 쌓기 |  |
| 계기 | 5~7화 | 태풍 특보로 마지막 배가 끊기고 소이가 등대에 고립됨 |  |
| 도입 | 1~4화 | 재하의 섬 생활과 소이의 조사 출장, 등대에서의 첫 충돌 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 1화, 정전된 등대 안에서 재하가 손전등 하나로 소이를 마중 나오는 장면
- [ ] 태풍 한가운데, 둘이 촛불 하나 두고 각자의 '떠나온 이유'를 반씩만 말하는 장면
- [ ] 마지막 화, 소이가 처음으로 카메라 셔터를 재하에게 맡기는 장면

**회차 끝 훅 아이디어**

- 6화 끝: 무선기 전원을 넣자 지지직거리며 육지가 아니라 엉뚱한 목소리가 흘러나온다 — 재하가 잃은 동료의 옛 교신 기록이었다는 걸 다음 화에서 암시
- 22화 끝: 소이의 휴대폰에 "철거 불가피" 초안이 메일로 도착하는 알림이 뜬다
