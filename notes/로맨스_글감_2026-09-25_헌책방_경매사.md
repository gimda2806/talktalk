# 로맨스 글감 노트 — 낙찰가보다 비싼 것

Sep 25, 2026 · @Claude (자동 생성)

> `notes/로맨스_글감_노트_템플릿.md`를 복제해 채운 글감 노트예요. 이번 회차 주제: 할머니의 유품과 경매.

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 폐업을 앞둔 골목 헌책방, 경매사가 서가 구석의 낡은 시집 한 권에 손을 뻗으며 "이건 얼마쯤 될까요"라고 혼잣말처럼 묻는다.
- **떠오른 대사:** "이 책, 파는 거 아니에요." / "안 팔아도 돼요. 그냥 저도, 얼마인지 알고 싶어서요."
- **떠오른 설정·관계:** 돌아가신 할머니의 헌책방을 혼자 지키는 여자와, 그 서가의 시집을 감정하러 온 대형 경매회사 고서적 담당자가 얽힌다. 시집 갈피에서 나온 편지 한 장이 사실 두 사람 조부모 세대의 못다 한 사랑 이야기임이 드러난다.
- **어디서 왔나:** 헌책 속에서 옛 연애편지가 발견됐다는 뉴스 기사, 그리고 "값을 매길 수 없는 것"에 대한 생각.
- **가장 강하게 느낀 감정 하나:** 애틋함

## 2단계 · 로그라인과 트로프

**로그라인:** 할머니의 헌책방 '책갈피'를 혼자 지키는 노유경이, 서가 한켠의 낡은 시집을 감정하러 온 경매사 강시완을 만나지만, 책갈피에서 나온 편지 한 장이 두 사람 조부모 세대의 못다 한 사랑을 들춰내면서 책방을 지키려는 마음과 그 마음에 값을 매기려는 마음이 부딪힌다.

- **작품 가제목:** 낙찰가보다 비싼 것
- **장르:** 현대 로맨스
- **배경:** 골목 헌책방 '책갈피' + 대형 경매회사
- **분위기:** 잔잔 · 힐링 (중반 애틋함)
- **핵심 트로프(최대 3개):** 라이벌(가치관 대립)에서 연인 / 조부모 세대 로맨스 액자식 / 공동 조사(계기로 얽힘)

## 3단계 · 인물 카드

| 항목 | 노유경 (A, 30세, 헌책방 '책갈피' 주인) | 강시완 (B, 33세, 고서적 담당 경매사) |
| --- | --- | --- |
| 한마디 인상 | 책값보다 책의 사연을 먼저 매기는 사람 | 뭐든 숫자로 바꿔야 마음이 놓이는 사람 |
| 결핍·상처 | 할머니를 잃은 슬픔을 책방을 지키는 일로 대신 앓는 중 — "책방을 접으면 할머니를 두 번 잃는 것 같다" | 전직 경매사였던 아버지의 "값을 못 매기면 의미도 없다"는 말 아래 자라, 감정도 값을 매겨야 안심함 |
| 겉으로 원하는 것 | 시집을 팔지 않고 책방을 지키는 것 | 이 시집으로 회사의 대형 경매 라인업을 성사시키는 것 |
| 사실 필요한 것 | 할머니를 놓아줘도 그 마음이 사라지지 않는다는 걸 아는 것 | 값을 매길 수 없는 것도 소중할 수 있다는 걸 배우는 것 |
| 연애를 막는 내면의 벽 | "가격이 매겨지는 순간 그 사연은 사라진다"는 믿음 | "감정가가 안 나오는 건 믿을 수 없다"는 습관 |
| 매력 포인트 | 손님 하나하나의 사연까지 기억하는 다정함 | 낡은 책 한 권의 내력을 집요하게 파고드는 진지함 |
| 말버릇·습관 | 책 상태를 설명할 때 사람 안부 묻듯 말한다("얘가 요즘 습기를 좀 먹었어요") | 뭐든 감정가부터 말하고 나서 상대 표정을 살핀다 |
| 상대에게만 보여 주는 모습 | 계산을 잠깐 멈추고 책장을 가만히 넘겨 보는 모습 | 유경 앞에서는 감정가를 말하다 말고 우물거리는 순간 |

## 4단계 · 관계와 갈등

- **끌리는 이유:** 같은 책을 정반대의 눈으로 보는 유일한 사람이라서.
- **외적 갈등:** 이 시집이 회사의 연중 최대 경매 라인업 핵심으로 지목됨(시완의 실적 압박) / 책방 건물 임대 계약 만료가 겹쳐 유경의 생계가 걸림.
- **내적 갈등:** 유경은 책을 팔면 할머니를 완전히 놓아버릴까 두렵고, 시완은 값으로 설명되지 않는 감정을 믿지 못한다.
- **두 사람의 힘의 균형:** 초반엔 계약과 감정가를 쥔 시완이 우위 → 편지 속 사연이 드러나며 진짜 이야기를 아는 유경 쪽으로 주도권이 넘어간다.
- **둘만의 상징물:** 시집 갈피에 눌러 말린 꽃잎, 그 아래 숨겨져 있던 편지.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 값을 매길 수 없는 것을 알아보는 눈을 갖게 된 안도감.

## 5단계 · 회차 구성

- **예상 분량:** 총 60화 (2권)
- **연재 플랫폼(예정):** 리디북스 / 카카오페이지

| 구간 | 회차 | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 두 사람이 편지의 사연을 엮은 작은 책을 함께 만드는 후일담 | |
| 결말 | 57~60화 | 책방은 지키고, 시집은 팔지 않되 두 사람이 그 이야기를 책으로 엮기로 함 | |
| 절정 | 51~56화 | 시완이 사표를 걸고 경매를 멈추며, 조부모의 진짜 사연(편지의 주인)을 밝힘 | |
| 위기 | 34~50화 | 실적 압박에 못 이긴 시완이 몰래 감정평가서를 제출 → 유경의 배신감, 동시에 임대 계약 만료로 책방 폐업 위기 | |
| 중간 전환 | 26~33화 | 시완이 처음으로 "이 책은 경매에 부치지 않겠다"는 말을 하려다 못 하는 밤, 감정 인정 | |
| 전개 | 10~25화 | 편지 속 사연을 함께 추적하며 가까워짐, 책방 임대 위기가 서서히 드러남 | |
| 계기 | 5~9화 | 시완이 시집 갈피에서 편지를 발견, 두 사람 조부모 세대의 이야기임을 알고 공동 조사 시작 | |
| 도입 | 1~4화 | 폐업 소문이 도는 책방에 시완이 찾아와 시집 감정을 요청하고, 유경이 거절 | |

**복선 역추적 표**

| 끝에 나오는 것 | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 두 사람이 편지 사연을 작은 책으로 엮음 | 유경이 손님들의 사연을 따로 노트에 적어 두는 습관 | 3화 |
| 시완이 경매장에서 사표를 던짐 | 시완이 "값이 안 나오면 의미 없다"는 아버지 말을 반복해서 인용 | 6화 |
| 마른 꽃잎이 조부모의 증표였음이 밝혀짐 | 유경이 그 꽃잎을 무심코 손끝으로 만지작거리는 장면 | 2화 |

**꼭 넣고 싶은 장면 목록**

- [ ] 시완이 처음으로 감정가를 말하다 말고 우물거리는 장면
- [ ] 두 사람이 함께 조부모 중 한쪽을 찾아가 편지의 사연을 확인하는 장면
- [ ] 시완이 사직서를 들고 경매장 마이크를 가로채는 장면

**회차 끝 훅 아이디어**

- 유경이 임대 계약서에 서명하려는 순간, 시완에게서 "그 책, 경매 목록에서 뺐습니다"라는 문자가 온다.
