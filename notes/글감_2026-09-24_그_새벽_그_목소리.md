# 글감 노트 · 그 새벽, 그 목소리 (가제)

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  방송국 옥상. 정식 생방송이 끝난 뒤, 한과 우진 둘이서만 마지막 "사연"을 주고받는다.
- 마지막 대사 한 줄:
  "이제 사연 안 보내도 돼요. 옆에서 말하면 되니까."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요?
  한은 얼굴을 마주한 채로도 솔직해지는 법을 배우고, 우진은 사고의 기억 없이도 사람을 태우고 대화할 수 있게 된다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요?
  우진이 한의 단골 택시기사였다는 사실이 방송 소재로 유출되어 청취자들 앞에 공개된다. 한은 우진을 지키지 못했다는 죄책감에, 우진은 다시 정체를 숨기고 침묵한다.
- 둘이 가장 많이 상처 주는 장면은?
  한이 방송 원고에 우진과의 일을 무심코 녹음분으로 흘려보낸 뒤, 우진이 "역시 나는 사연거리였구나"라고 말하는 장면.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는?
  결말이 '옆에서 말하면 된다'라면, 출발은 '서로 얼굴도 이름도 모른 채 매일 밤 같은 시간만 공유한다'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 신호 대기 중 우진이 처음으로 한의 이름을 부름 | 초반부터 우진이 손님 이름 부르길 어려워하는 습관 | 1~2화 |
| 옥상에서의 마지막 생방송 | 한이 옥상에서 혼자 사연을 읽는 버릇 | 3화 |
| "이제 사연 안 보내도 돼요" 대사 | 매일 자정 정각에 걸려오는 전화라는 규칙 | 4~5화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 자정 라디오 부스, 창밖엔 눈. 생방송 중 걸려온 전화를 스피커로 내보내다가 작가가 그 목소리에 얼어붙는다.
- **떠오른 대사:** "저 그쪽 아는데요. 목소리 말고, 얼굴로요."
- **떠오른 설정·관계:** 심야 라디오 사연 작가와, 매일 같은 시간 라디오를 들으며 사연을 보내는 택시기사가 사실 매주 같은 정류장에서 서로를 태우고 내려 준 사이였다는 걸 모른 채 지내다 우연히 마주친다.
- **어디서 왔나:** 새벽 택시 안에서 들은 라디오 사연 코너
- **가장 강하게 느낀 감정 하나:** 그리움 섞인 반가움

## 2단계 · 로그라인과 트로프

**공식:** 얼굴 없는 목소리로만 서로를 위로하던(상황)에 놓인 라디오 작가 이한(주인공 A)이 매일 밤 사연을 보내는 택시기사 강우진(주인공 B)을 만나지만, 방송국 규정과 서로의 상처 때문(걸림돌)에 목소리로 쌓은 믿음이 얼굴을 마주한 뒤에도 그대로일지(질문/긴장) 망설인다.

- **로그라인:** 얼굴 없는 말로만 서로를 위로하던 심야 라디오 작가 이한과 택시기사 강우진이 우연히 서로의 정체를 알게 되지만, 목소리로 쌓은 믿음이 얼굴을 마주한 뒤에도 그대로일지 확신하지 못해 망설인다.
- **작품 가제목:** 그 새벽, 그 목소리
- **장르:** 현대 로맨스
- **배경:** 심야 라디오 방송국, 새벽 택시
- **분위기:** 잔잔 / 힐링 / 살짝 달달
- **핵심 트로프(최대 3개):** 정체를 모르는 채 쌓은 교감, 매일 같은 시간 스치는 인연, 비밀 정체 발각

## 3단계 · 인물 카드

| 항목 | 주인공 A (이한) | 주인공 B (강우진) |
| --- | --- | --- |
| 이름·나이·직업 | 이한, 30, 심야 라디오 구성작가 | 강우진, 32, 심야 택시기사 |
| 한마디 인상 | 남의 사연은 끝까지 들어주면서 제 얘기는 절대 안 하는 사람 | 말수 적고 무뚝뚝하지만 라디오 앞에서만 솔직해지는 사람 |
| 결핍·상처 | 과거 소개팅에서 외모로 평가받은 뒤 '얼굴을 보여주면 실망시킨다'는 믿음 | 손님을 잃을 뻔한 사고 이후 사람 태우고도 대화를 피함(죄책감) |
| 겉으로 원하는 것 | 청취자들에게 완벽한 위로를 주는 목소리로만 남는 것 | 아무 사고 없이 조용히 운전만 하는 것 |
| 사실 필요한 것 | 얼굴을 보여줘도 실망하지 않을 사람 | 얼굴을 맞대고도 자신을 봐줄 사람 |
| 연애를 막는 내면의 벽 | 얼굴을 보이는 순간 지금의 다정함이 깨질 거라는 두려움 | 사고의 기억이 얽힌 사람과 다시 가까워지는 것에 대한 죄책감 |
| 매력 포인트 | 상대 말을 끝까지 들어주고, 새벽에 우는 사람도 웃게 만드는 멘트 | 무뚝뚝하지만 사연을 읽어 줄 때 담기는 다정함 |
| 말버릇·습관 | 방송 멘트로만 진심을 흘림 | 손님 이름을 부르지 못하고 "손님"이라고만 함 |
| 상대에게만 보여 주는 모습 | 방송 끝나고 혼자 옥상에서 사연을 소리 내어 읽는 모습 | 라디오 주파수를 절대 바꾸지 않는 고집 |

## 4단계 · 관계와 갈등

- **끌리는 이유:** 서로의 '진짜 얼굴'을 몰라도 가장 솔직한 말을 주고받은 사이라서.
- **이어질 수 없는 이유 – 외적 갈등:** 방송국 규정상 작가와 청취자의 사적인 만남이 금지되어 있고, 우진이 한의 단골 기사였다는 사실이 알려지면 방송 소재로 소비될 위험이 있다.
- **이어질 수 없는 이유 – 내적 갈등:** 한은 얼굴을 보이면 지금의 다정함이 깨질까 두렵고, 우진은 사고의 기억이 얽힌 사람과 다시 가까워지는 데 죄책감을 느낀다.
- **두 사람의 힘의 균형:** 처음엔 한이 '목소리'로 우위를 가진다(청취자를 위로하는 입장). 우진의 사고 사연이 방송을 타며 그가 감정적으로 무너지는 순간 균형이 뒤집힌다.
- **둘만의 상징물:** 매일 밤 12시 정각에 걸려오는 전화, 택시 라디오에 고정된 주파수.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 정체를 몰라도 이미 사랑이었다는 먹먹함, 뒤늦게 서로를 알아보는 벅참.

## 5단계 · 회차 구성

- **예상 분량:** 총 75화 (3권 기준)
- **연재 플랫폼(예정):** 미정 (카카오페이지 / 리디 검토)

| 구간 | 회차 (3권·약 75화 기준) | 이 구간의 역할 | 내 장면 메모 |
| --- | --- | --- | --- |
| 외전 | (선택) | 두 사람이 함께 라디오를 진행하는 후일담 |  |
| 결말 | 3권 · 69~75화 | 옥상에서의 마지막 생방송, 관계 확정 |  |
| 절정 | 3권 · 59~68화 | 우진의 사고 사연이 방송을 타고, 한이 그를 보호하려 나선다 |  |
| 위기 | 2권 후반~3권 초 · 39~58화 | 우진의 정체 유출, 둘 다 침묵 |  |
| 중간 전환 | 2권 중반 · 31~38화 | 택시 뒷좌석에서 서로의 정체를 알아채는 장면 |  |
| 전개 | 1권 후반~2권 초 · 13~30화 | 매일 자정 전화로 가까워짐, 서로를 모른 채 스치는 아이러니 쌓기 |  |
| 계기 | 1권 · 8~12화 | 우진의 사연이 처음 방송을 탐, 한이 그 목소리에 끌림 |  |
| 도입 | 1권 · 1~7화 | 각자의 새벽 일상과 결핍, 눈 오는 밤 첫 방송 장면 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 눈 오는 밤, 라디오 부스에서 우진의 사연이 처음 전파를 타는 장면
- [ ] 택시 뒷좌석에서 한이 우진의 목소리를 알아채는 장면
- [ ] 옥상에서의 마지막 생방송, "이제 사연 안 보내도 돼요" 대사

**회차 끝 훅 아이디어**

- 매 회 말미, 자정을 알리는 전화벨과 함께 다음 사연의 첫 문장만 들려주고 정체를 암시한 채 끊기
