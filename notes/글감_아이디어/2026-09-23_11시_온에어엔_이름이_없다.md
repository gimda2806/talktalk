# 글감 노트 · 온에어엔 이름이 없다

Sep 23, 2026 · 11시 스케줄 생성 (템플릿: [로맨스_글감_노트_템플릿.md](../로맨스_글감_노트_템플릿.md) 사용)

## 내 방식 · 끝에서 거꾸로 설계하기

**3권 (도착지)**

- 마지막 장면은 어디서, 누가, 무엇을 하고 있나요?
  → 공개방송 무대 뒤, 은서가 처음으로 자기 이름으로 사연을 써서 태오에게 직접 읽어 준다.
- 마지막 대사 한 줄: "오늘은 사연 주인공이 저예요. 이름은… 은서예요."
- 처음과 비교해 두 사람은 각각 어떻게 변해 있나요? 은서는 익명 뒤에 숨지 않고 자기 얘기를 꺼낼 수 있게 됐고, 태오는 무대 밖에서도 가면을 벗고 '태오'가 아니라 본명으로 불리는 걸 편하게 받아들인다.

**2권 (가장 멀어진 지점)**

- 3권의 행복이 값지게 느껴지려면, 2권 끝에서 둘은 무엇을 잃어야 하나요? → 태오의 정체가 스캔들 기사로 먼저 터지면서, 은서가 만든 코너 자체가 '기획된 열애설'로 오해받아 폐지 위기에 놓인다. 태오는 은서를 지키려 방송국에 발길을 끊는다.
- 둘이 가장 많이 상처 주는 장면은? 은서가 "저는 그쪽 팬이었던 적 없어요, 그냥 작가였어요"라고 선을 긋고, 태오는 "그럼 내가 보낸 사연들도 다 일이었어요?"라고 되묻는다.

**1권 (출발지)**

- 결말과 가장 반대인 출발 상태는? 결말이 '이름으로 서로를 부른다'라면, 출발은 '목소리와 필명으로만 존재한다'.

**복선 역추적 표**

| 끝에 나오는 것 (장면·대사·물건) | 앞에 심어 둘 것 | 심을 회차 |
| --- | --- | --- |
| 은서가 직접 쓴 사연을 낭독 | 1화, 은서가 남의 사연은 잘 쓰면서 자기 얘기는 한 줄도 못 쓰는 메모장 보여주기 | 1화 |
| "이름은 은서예요" 대사 | 태오가 몇 년째 은서를 필명 '야간비행'으로만 부르는 설정 반복 | 8화, 20화 |
| 태오가 무대 밖에서도 본명으로 불리길 원함 | 태오가 인터뷰에서 "무대 위 이름 말고 그냥 이름으로 불린 지 오래됐다"고 흘리는 장면 | 5화 |

## 1단계 · 번뜩임 기록

- **떠오른 장면:** 매주 화요일 새벽 2시, 신청곡과 짧은 사연만 보내고 끝까지 이름을 밝히지 않는 단골 청취자. 어느 날 그 필명의 주인이 게스트로 방송국 로비에 나타난다.
- **떠오른 대사:** "저 사실 그 사람 알아요. 근데 모르는 척해야 해요."
- **떠오른 설정·관계:** 심야 라디오 코너를 쓰는 작가와, 몇 년째 익명으로 사연을 보내온 인기 밴드 보컬이 게스트 출연을 계기로 서로의 얼굴을 알아버림.
- **어디서 왔나:** 심야 라디오 방송에서 매번 같은 필명으로 사연을 보내는 청취자가 대체 누굴까 궁금해하다가.
- **가장 강하게 느낀 감정 하나:** 그리움

> 씨앗은 어떤 모양이든 심어 두면 돼요. 감정 한 단어가 나중에 이야기의 나침반이 돼요.

## 2단계 · 로그라인과 트로프

**로그라인:** 남의 사연만 대신 써 주며 자기 얘기는 숨겨 온 라디오 작가 은서가, 몇 년째 필명으로만 사연을 보내온 밴드 보컬 태오를 게스트 출연으로 마주치지만, 얼굴을 알아버린 순간 목소리 뒤에 숨어 있던 안전한 거리가 사라져 버렸을 때 그들은 서로에게 진짜 이름으로 다가갈 수 있을까?

- **작품 가제목:** 온에어엔 이름이 없다
- **장르:** 현대 로맨스
- **배경:** 심야 라디오 방송국, 공개방송 무대, 밴드 연습실
- **분위기:** 잔잔 / 달달 / 살짝 애틋
- **핵심 트로프(최대 3개):** 익명 소통에서 정체 공개, 짝사랑(사연 너머 마음), 유명인×평범인

## 3단계 · 인물 카드

| 항목 | 주인공 A (은서) | 주인공 B (태오) |
| --- | --- | --- |
| 이름·나이·직업 | 강은서, 29세, 심야 라디오 코너 작가 | 이태오, 31세, 인디 밴드 보컬 |
| 한마디 인상 | 남의 이야기는 귀신같이 쓰는데 자기 얘기는 한 줄도 못 씀 | 무대 위에서만 진짜 얼굴을 보여주는 사람 |
| 결핍·상처 | 예전에 자기 이별담을 각색해 사연 코너로 낸 뒤로, 자기 얘기를 하면 소비될까 봐 숨음 | 데뷔 후로 '태오'라는 무대 이름 뒤에 본명을 감추고 삶 |
| 겉으로 원하는 것 | 눈에 띄지 않는 삶, 이름 없이 방송 뒤에만 존재하는 것 | 스캔들 없이 밴드를 지키는 것 |
| 사실 필요한 것 | 자기 이야기를 자기 목소리로 말할 용기 | 유명하지 않은 사람처럼 있는 그대로 알아봐 주는 사람 |
| 연애를 막는 내면의 벽 | "사연 제공자와 사적으로 얽히면 작가 자격이 없다"는 원칙 | "정체를 들키는 순간 이 관계도 이용당할 것"이라는 두려움 |
| 매력 포인트 | 무뚝뚝하지만 남의 마음을 정확히 짚어내는 문장력 | 무대 밖에서는 서툴고 다정한 반전 |
| 말버릇·습관 | 힘든 얘기 나오면 화제를 사연 코너 이야기로 돌림 | 하고 싶은 말 대신 노래 가사로 흘림 |
| 상대에게만 보여 주는 모습 | 자신이 겪은 이별을 처음으로 글로 써서 보여줌 | 무대 위 텐션 없이, 더듬거리며 진심을 말하는 모습 |

> 짧은 예: A는 '내 얘기를 하면 소비된다'고 믿고, B는 '있는 그대로 봐 준다'고 증명해 주는 사람. 이러면 사건이 없어도 둘 사이에 긴장이 생겨요.

## 4단계 · 관계와 갈등

- **끌리는 이유 (왜 하필 이 사람인가):** 태오는 몇 년간 은서가 쓴 문장(사연에 대한 답글)에 위로받아 온 유일한 익명 청취자였고, 은서는 자기 이야기를 처음으로 들어 주는 사람이 태오라는 걸 알게 된다.
- **이어질 수 없는 이유 – 외적 갈등:** 소속사의 스캔들 경계, 밴드 재계약 시즌, 라디오 코너가 '기획 열애설'로 오해받아 폐지 위기에 놓임.
- **이어질 수 없는 이유 – 내적 갈등:** 은서는 '사연 제공자와 얽히면 안 된다'는 직업 원칙, 태오는 '정체가 알려지면 관계도 소비될 것'이라는 두려움.
- **두 사람의 힘의 균형:** 처음엔 태오가 유명세로, 은서가 익명성으로 서로를 가려 줌(대등). 태오의 정체가 터지면서 태오 쪽이 잃을 게 많아지고, 은서가 그를 지키기 위해 먼저 나서는 쪽으로 뒤집힘.
- **둘만의 상징물:** 태오가 매주 신청하는 오래된 인디밴드 노래 한 곡.
- **이 이야기가 끝났을 때 독자가 느낄 감정:** 뭉클한 안도감 — 숨어 있던 사람이 이름을 되찾는 걸 지켜본 기분.

- **예상 분량:** 총 75화 (3권 기준)
- **연재 플랫폼(예정):** 미정

| 전개 | 1권 후반~2권 초 · 13~30화 | 사연을 핑계로 메시지를 주고받으며 가까워짐, 태오의 정체를 은서가 서서히 눈치챔 |  |
| 계기 | 1권 · 8~12화 | 태오가 밴드 인터뷰 게스트로 라디오국을 방문, 로비에서 은서와 마주침 |  |
| 도입 | 1권 · 1~7화 | 은서의 심야 코너 일상과 '자기 얘기는 못 쓰는' 결핍, 필명 '야간비행'의 사연이 처음 소개됨 |  |

**꼭 넣고 싶은 장면 목록**

- [ ] 은서가 태오인 줄 모르고 '야간비행' 사연에 진심 어린 답장을 낭독하는 장면
- [ ] 공개방송 대기실에서 둘만 남았을 때, 태오가 신청곡을 직접 흥얼거려 정체를 들킬 뻔하는 장면
- [ ] 스캔들 기사 이후, 은서가 방송국 로비에서 태오를 기다리는 장면(팔 년 전 정류장 모티프와 대비되는 '짧은 기다림')

**회차 끝 훅(다음 화를 누르게 만드는 마지막 장면) 아이디어**

- 게스트로 온 태오가 부스 유리창 너머로 은서를 보며 신청곡 제목을 입모양으로만 말하고 사라진다.
- 스캔들 기사 헤드라인이 뜨는 순간, 은서의 핸드폰에 '야간비행'이라는 이름으로 마지막 메시지가 도착한다: "저 이제 필명 그만 쓸게요."
