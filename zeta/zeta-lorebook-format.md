# 제타 설정집(로어북) 포맷

제타 설정집 탭에 넣는 로어북 항목을 만들기 위한 전용 포맷.
`{{user}}`는 유저, `{{char}}`는 캐릭터를 가리키는 제타 치환어.

---

## 1. 화면 구조와 제한

| 구역 | 칸 | 제한 | 필수 |
| --- | --- | --- | --- |
| 설정집 정보 | 제목 | 미확인 | 필수 |
| 설정집 정보 | 소개 (제목과 함께 보이는 짧은 소개) | 50자 | - |
| 로어북 항목 | 제목 | 20자 | - |
| 로어북 항목 | 키워드 | 쉼표(,) 구분, 각 20자 이내, 최대 5개 | 필수 |
| 로어북 항목 | 내용 | 500자 | 필수 |
| 로어북 | 항목 수 | 최대 50개 — 작품 설정집은 4~6개(조연·소품·동물은 선택) | - |
| 플롯 연결 | 연결할 플롯(캐릭터) 선택 | 여러 플롯에 연결 가능 | - |

> 설정집 내용은 공개 화면에서 다른 사람이 볼 수 있다. 결말 스포일러는 넣지 않는다.

---

## 2. 작동 원리

로어북은 **키워드 알람**이다. 대화에 키워드가 나오면 그 항목의 내용이 AI에게 전달되고, 키워드가 나오지 않으면 전달되지 않는다.

그래서 항목은 두 종류로 나눈다.

| 종류 | 언제 불려오나 | 키워드 고르는 법 | 넣을 내용 |
| --- | --- | --- | --- |
| 상시형 | 거의 매 턴 | `{{user}}`, `{{char}}`, `system`, `했다`, `말했다`처럼 매번 등장하는 단어 | 문체, 진행 방식, 인물 연기, 관계 단계 같은 규칙 |
| 상황형 | 특정 소재가 나올 때만 | 그 소재의 이름, 별명, 관련 단어 | 조연, 장소, 소품, 이벤트 |

---

## 3. 작성 원칙

1. **주어를 꼭 쓴다.** 내용만 따로 전달되므로 "다정하다"가 아니라 "강해솔은 다정하다"처럼 대상을 밝힌다. (제타 안내: '빨갛다' 대신 '사과는 빨갛다')
2. **항목 하나에 주제 하나.** 여러 소재를 섞으면 엉뚱한 키워드에 엉뚱한 정보가 따라온다.
3. **번호 목록으로 쓴다.** 규칙형은 `1. 2. 3.`으로 나누면 AI가 지키기 쉽다.
4. **"하지 마"보다 "이렇게 해"를 함께 쓴다.** 금지만 적으면 대신 무엇을 할지 몰라 어색해진다.
   - 예: "떠보는 반응은 한 번까지만 하고, 그 이후에는 솔직하게 반응하거나 행동으로 이야기를 진행한다."
5. **키워드는 짧은 어근으로.** '보리가', '보리는' 대신 '보리'처럼 조사를 뺀다.
6. **키워드 겹침을 확인한다.** 짧은 키워드는 다른 단어 안에서도 걸릴 수 있다. (예: '보리'는 '보리차'에서도 불려올 수 있음. 떡밥으로 일부러 노린다면 그대로 둔다)
7. **너무 흔한 단어는 상황형에 쓰지 않는다.** '손', '말' 같은 단어는 상시형 규칙에만 쓴다.
8. **가장 중요한 규칙은 캐릭터 설명에도 한 줄 넣는다.** 키워드가 안 나오는 턴에는 로어북이 빠질 수 있다.

## 4. 항목 유형별 템플릿

### 4-1. 규칙형 (상시형)

제목

```text
(규칙 이름, 예: 진행규칙)
```

키워드

```text
{{user}}, {{char}}, system, 했다, 말했다
```

내용

```text
1. (지켜야 할 규칙과 대신 할 행동)
2. (지켜야 할 규칙과 대신 할 행동)
3. (지켜야 할 규칙과 대신 할 행동)
```

### 4-2. 인물형 (조연)

제목

```text
(조연 이름)
```

키워드

```text
(이름), (성 빼고 부르는 이름), (직함), (별명), (주인공이 부르는 호칭)
```

내용

```text
(이름)은 (나이) (성별)이며 (직업·역할)이다. (이름)은 (성격 한두 줄). (이름)은 {{char}}를 (호칭)이라고 부르고, {{user}}를 (호칭)이라고 부른다. (이름)은 (이야기 속 역할: 두 사람을 이어 주는 사람, 라이벌 등)이다. (이름)은 (말버릇이나 대표 대사).
```

### 4-3. 장소형

제목

```text
(장소 이름)
```

키워드

```text
(장소 이름), (줄임말), (그 장소의 대표 사물)
```

내용

```text
(장소 이름)은 (위치)에 있는 (어떤 곳)이다. (장소 이름)은 (분위기: 빛, 소리, 냄새). (장소 이름)에서는 주로 (자주 일어나는 일)이 일어난다. (장소 이름)에는 (특징적인 사물)이 있다.
```

### 4-4. 소품·동물형

제목

```text
(소품·동물 이름)
```

키워드

```text
(이름), (종류), (관련 행동이나 단어)
```

내용

```text
(이름)은 {{char}}가 (키우는/아끼는) (종류)이다. (이름)은 (외모·성격). (이름)은 (이야기 속 역할: 둘을 이어 주는 장치, 마음이 드러나는 장치 등). (이름)은 (대표 행동).
```

### 4-5. 이벤트형

제목

```text
(이벤트 이름)
```

키워드

```text
(이벤트를 부르는 단어), (계절·날짜), (관련 사물)
```

내용

```text
(키워드)가 언급되면 (이벤트 상황)이 일어날 수 있다. {{char}}는 이때 (평소와 다른 반응). 이 이벤트는 (설렘/애틋함/서운함/위기 등 작품의 메인 분위기에 맞는) 장면이며, (결말은 쓰지 않고 {{char}}의 반응이 어느 쪽으로 기우는지만).
```

## 5. 공통 설정집

최신 공통 설정집은 `zeta-common-lorebook.md` 하나의 파일에서만 관리한다. 이 파일에는 사본을 두지 않는다.

## 6. 작품별 상황형 항목 예시

### 〈윗집 남자가 시끄럽다〉

**쪽지 (소품형)**

```text
쪽지, 포스트잇, 메모, 문 앞
```

```text
쪽지는 {{user}}와 차은호가 층간소음 때문에 주고받기 시작한 메모다. 은호는 {{user}}의 쪽지를 전부 냉장고에 붙여 모아두고 있다. 은호는 쪽지에 답장할 때 사탕이나 작은 간식을 함께 붙여둔다.
```

## 7. 만들기 순서

1. **상시형 먼저**: 공통 설정집(`zeta-common-lorebook.md`)을 모든 플롯에 연결한다.
2. **작품 전용 설정집 만들기**: 작품마다 설정집을 하나씩 따로 만든다.
3. **조연 → 장소 → 소품 → 이벤트** 순서로 상황형 항목을 추가한다. 조연과 소품·동물은 선택 사항이라 없으면 건너뛴다.
4. **플롯 연결 탭**에서 해당 작품에만 연결한다.
5. **새 대화로 테스트**: 키워드를 일부러 말해보고 AI가 내용을 반영하는지 확인한다.
