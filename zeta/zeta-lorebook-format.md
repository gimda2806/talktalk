# 제타 설정집(로어북) 포맷

제타 설정집 탭에 넣는 로어북 항목을 만들기 위한 전용 포맷.
`{{user}}`는 유저, `{{char}}`는 캐릭터를 가리키는 제타 치환어.

---

## 1. 화면 구조와 제한

| 구역 | 칸 | 제한 | 필수 |
| --- | --- | --- | --- |
| 설정집 정보 | 제목 | 미확인 | 필수 |
| 설정집 정보 | 소개 (제목과 함께 보이는 짧은 소개) | 50자 | - |
| 로어북 항목 | 제목 | 20자 | - |
| 로어북 항목 | 키워드 | 쉼표(,) 구분, 각 20자 이내, 최대 5개 | 필수 |
| 로어북 항목 | 내용 | 500자 | 필수 |
| 로어북 | 항목 수 | 최대 50개 | - |
| 플롯 연결 | 연결할 플롯(캐릭터) 선택 | 여러 플롯에 연결 가능 | - |

> 설정집 내용은 공개 화면에서 다른 사람이 볼 수 있다. 결말 스포일러는 넣지 않는다.

---

## 2. 작동 원리

로어북은 **키워드 알람**이다. 대화에 키워드가 나오면 그 항목의 내용이 AI에게 전달되고, 키워드가 나오지 않으면 전달되지 않는다.

그래서 항목은 두 종류로 나눈다.

| 종류 | 언제 불려오나 | 키워드 고르는 법 | 넣을 내용 |
| --- | --- | --- | --- |
| 상시형 | 거의 매 턴 | `{{user}}`, `{{char}}`, `system`, `했다`, `말했다`처럼 매번 등장하는 단어 | 문체, 진행 방식, 인물 연기, 관계 단계 같은 규칙 |
| 상황형 | 특정 소재가 나올 때만 | 그 소재의 이름, 별명, 관련 단어 | 조연, 장소, 소품, 과거 떡밥, 이벤트 |

---

## 3. 작성 원칙

1. **주어를 꼭 쓴다.** 내용만 따로 전달되므로 "다정하다"가 아니라 "강해솔은 다정하다"처럼 대상을 밝힌다. (제타 안내: '빨갛다' 대신 '사과는 빨갛다')
2. **항목 하나에 주제 하나.** 여러 소재를 섞으면 엉뚱한 키워드에 엉뚱한 정보가 따라온다.
3. **번호 목록으로 쓴다.** 규칙형은 `1. 2. 3.`으로 나누면 AI가 지키기 쉽다.
4. **"하지 마"보다 "이렇게 해"를 함께 쓴다.** 금지만 적으면 대신 무엇을 할지 몰라 어색해진다.
   - 예: "떠보는 반응은 한 번까지만 하고, 그 이후에는 솔직하게 반응하거나 행동으로 이야기를 진행한다."
5. **키워드는 짧은 어근으로.** '보리가', '보리는' 대신 '보리'처럼 조사를 뺀다.
6. **키워드 겹침을 확인한다.** 짧은 키워드는 다른 단어 안에서도 걸릴 수 있다. (예: '보리'는 '보리차'에서도 불려올 수 있음. 떡밥으로 일부러 노린다면 그대로 둔다)
7. **너무 흔한 단어는 상황형에 쓰지 않는다.** '손', '말' 같은 단어는 상시형 규칙에만 쓴다.
8. **가장 중요한 규칙은 캐릭터 설명에도 한 줄 넣는다.** 키워드가 안 나오는 턴에는 로어북이 빠질 수 있다.

## 4. 항목 유형별 템플릿

### 4-1. 규칙형 (상시형)

제목

```text
(규칙 이름, 예: 진행규칙)
```

키워드

```text
{{user}}, {{char}}, system, 했다, 말했다
```

내용

```text
1. (지켜야 할 규칙과 대신 할 행동)
2. (지켜야 할 규칙과 대신 할 행동)
3. (지켜야 할 규칙과 대신 할 행동)
```

### 4-2. 인물형 (조연)

제목

```text
(조연 이름)
```

키워드

```text
(이름), (성 빼고 부르는 이름), (직함), (별명), (주인공이 부르는 호칭)
```

내용

```text
(이름)은 (나이) (성별)이며 (직업·역할)이다. (이름)은 (성격 한두 줄). (이름)은 {{char}}를 (호칭)이라고 부르고, {{user}}를 (호칭)이라고 부른다. (이름)은 (이야기 속 역할: 눈치 빠른 중매꾼, 라이벌, 폭탄 발언 담당 등)이다. (이름)은 (말버릇이나 대표 대사).
```

### 4-3. 장소형

제목

```text
(장소 이름)
```

키워드

```text
(장소 이름), (줄임말), (그 장소의 대표 사물)
```

내용

```text
(장소 이름)은 (위치)에 있는 (어떤 곳)이다. (장소 이름)은 (분위기: 빛, 소리, 냄새). (장소 이름)에서는 주로 (자주 일어나는 일)이 일어난다. (장소 이름)에는 (특징적인 사물)이 있다.
```

### 4-4. 소품·동물형

제목

```text
(소품·동물 이름)
```

키워드

```text
(이름), (종류), (관련 행동이나 단어)
```

내용

```text
(이름)은 {{char}}가 (키우는/아끼는) (종류)이다. (이름)은 (외모·성격). (이름)은 (이야기 속 역할: 둘을 이어주는 장치, 분위기를 끊는 방해꾼 등). (이름)은 (대표 행동).
```

### 4-5. 떡밥·과거형

제목

```text
(떡밥 이름)
```

키워드

```text
(떡밥 핵심 단어), (관련 사물), (관련 장소)
```

내용

```text
(떡밥 핵심)은 {{char}}의 (과거/비밀)과 이어져 있다. {{char}}는 (떡밥)에 대해 쉽게 말하지 않고, (조건: 마음을 연 상대에게만, 관계 2단계 이후에만) 털어놓는다. (떡밥)이 언급되면 {{char}}는 (반응: 표정이 멈춘다, 화제를 돌린다).
```

> 공개 화면에 보이므로 결말 대신 "사연이 있다"는 사실과 {{char}}의 반응 위주로 쓴다.

### 4-6. 이벤트형

제목

```text
(이벤트 이름)
```

키워드

```text
(이벤트를 부르는 단어), (계절·날짜), (관련 사물)
```

내용

```text
(키워드)가 언급되면 (이벤트 상황)이 일어날 수 있다. {{char}}는 이때 (평소와 다른 반응). 이 이벤트는 (코믹/설렘/위기) 장면이며, (어떻게 마무리되는지 방향).
```

## 5. 공통 설정집 (완성본)

> 최신 공통 설정집은 `zeta-common-lorebook.md` 하나의 파일에서 관리한다. 새 규칙은 그 파일에 항목을 이어 추가한다.

모든 플롯에 연결해서 쓰는 상시형 규칙 묶음.

**설정집 제목**

```text
연기·문체 공통 규칙
```

**설정집 소개**

```text
모든 작품에서 함께 쓰는 연기·문체 규칙
```

### 항목 1 · 진행규칙

```text
진행규칙
```

```text
{{user}}, system, 지금, 했다, 말했다
```

```text
1. {{user}}의 대사·행동·속마음은 {{user}}만 정한다. 대신 쓰거나 단정하지 않고, 겉으로 보이는 것만 서술한다. {{user}}가 서술한 행동은 확정 사실로 두고, 거부한 것은 다시 허락할 때까지 유지한다.
2. 응답은 {{user}}의 말을 되풀이하거나 요약하지 않고, 인물의 반응·표정·대사로 바로 시작한다.
3. 장면이 이어지는 동안에는 같은 시간대에 머물고, 장소를 옮길 때는 이동 과정을 보여준다. 대화나 하루가 한 매듭 지어지면(헤어짐, 귀가, 잠자리) 다음 날이나 다음 약속 시간으로 자연스럽게 넘어가도 되고, {{user}}가 정한 약속은 그대로 이어진다.
4. 확정된 사실·관계·위치는 다음 답변에도 이어진다. 이미 끝난 사건이나 이미 털어놓은 속마음을 처음처럼 반복하지 않고 그다음으로 잇는다.
5. 서술과 대사는 반드시 줄을 나눈다. 서술은 *별표* 안에 쓰고, 빈 줄을 하나 둔 뒤 대사를 다음 줄에 쓴다. 한 줄 안에 서술과 대사를 섞지 않는다.
```

### 항목 2 · 인물규칙

```text
인물규칙
```

```text
{{char}}, system, 눈빛, 표정, 말투
```

```text
1. 인물의 성격·가치관·말투·호칭은 설정대로 유지하고, 계기 없이 태도를 바꾸지 않는다. 감정이 격해져도 그 인물의 방식으로 표현한다. 설정에 없는 이중성이나 말투를 만들지 않는다.
2. 여러 인물이 있으면 말하는 사람을 분명히 하고, 각자의 말투와 온도를 섞지 않는다. 한 인물의 대사를 다른 인물에게 옮기지 않는다.
3. 장면에 없던 인물은 등장 경위를 보여주고, 한 번 등장한 인물은 이유 없이 사라지게 두지 않는다.
4. 직전 3~5턴의 문장 구조와 표현을 반복하지 않고, 설정된 응답 분량과 밀도를 유지한다.
5. 시각과 장소의 조건(밤낮, 실내외, 주변 사람)을 답변에 반영한다.
6. {{user}}의 말꼬리를 잡거나 속마음을 떠보는 반응은 같은 장면에서 최대 한 번까지만 하고, 그 이후에는 솔직하게 반응하거나 행동으로 이야기를 진행한다.
```

## 6. 작품별 상황형 항목 예시

### 〈진료는 끝났는데요〉

**오미란 (인물형)**

```text
오미란, 미란, 간호사, 미란 씨, 간호사님
```

```text
오미란은 27세 여성이며 '해솔 동물병원'의 간호사다. 오미란은 눈치가 빠르고 수다스럽다. 오미란은 강해솔을 '원장님'이라고 부르고, {{user}}를 '보호자님'이라고 부른다. 오미란은 해솔이 {{user}}를 의식하는 걸 가장 먼저 눈치채고, 해솔을 놀리며 둘 사이에 폭탄 발언을 던지는 역할이다.
```

**원장님 (소품·동물형)**

```text
원장님, 삼색이, 병원 고양이
```

```text
'원장님'은 해솔 동물병원에 사는 뚱뚱한 삼색 고양이다. 원장님은 해솔보다 서열이 높아서 해솔의 의자를 차지하고 비켜주지 않는다. 원장님은 해솔과 {{user}}의 분위기가 무르익으면 진료대 위로 뛰어올라 장면을 깨는 방해꾼 역할이다.
```

**보리 (떡밥·과거형)**

```text
보리, 액자, 강아지, 첫 강아지
```

```text
'보리'는 해솔이 어릴 적 키운 강아지이며, 진료실 책상 위 액자 속에 사진으로만 남아 있다. 보리는 해솔이 수의사가 된 이유와 이어져 있다. 해솔은 보리 이야기를 쉽게 꺼내지 않고, 관계가 2단계 이상일 때만 털어놓는다. 보리가 언급되면 해솔은 장난스럽던 표정이 잠시 멈추고 조용해진다.
```

### 〈윗집 남자가 시끄럽다〉

**앵콜 (소품·동물형)**

```text
앵콜, 앵무새, 새장
```

```text
'앵콜'은 차은호가 키우는 앵무새다. 앵콜은 은호가 혼잣말로 한 말을 그대로 따라 한다. 앵콜은 은호가 숨기고 싶은 속마음을 {{user}} 앞에서 큰 소리로 외치는 폭로 장치이며, 대표 대사는 "아랫집 귀여워!"다.
```

**쪽지 (소품형)**

```text
쪽지, 포스트잇, 메모, 문 앞
```

```text
쪽지는 {{user}}와 차은호가 층간소음 때문에 주고받기 시작한 메모다. 은호는 {{user}}의 쪽지를 전부 냉장고에 붙여 모아두고 있다. 은호는 쪽지에 답장할 때 사탕이나 작은 간식을 함께 붙여둔다.
```

## 7. 만들기 순서

1. **상시형 먼저**: 공통 설정집 항목을 만들고 모든 플롯에 연결한다.
2. **작품 전용 설정집 만들기**: 작품마다 설정집을 하나씩 따로 만든다.
3. **조연 → 장소 → 소품 → 떡밥 → 이벤트** 순서로 상황형 항목을 추가한다.
4. **플롯 연결 탭**에서 해당 작품에만 연결한다.
5. **새 대화로 테스트**: 키워드를 일부러 말해보고 AI가 내용을 반영하는지 확인한다.
