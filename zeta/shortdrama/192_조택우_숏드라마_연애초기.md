## 편집 순서
> 연결: C 클립의 끝 프레임 = 설렘 스틸 = 설렘 클립의 첫 프레임이라 C → 설렘 클립은 컷 없이 이어 붙이고, 설렘 클립 끝의 굳었다 웃는 그림에서 D로 넘어간다.
> 전환: 블록 안과 긴장 구간(C → 설렘 → D)은 모두 하드 컷. 잠깐 시간이 흐르는 B2 → C 사이만 0.3초 디졸브(같은 대기실, 소파에 앉은 뒤). 스와이프·줌 전환·플래시 같은 화려한 전환 효과는 쓰지 않는다.
> 임계점 정지: 설렘 클립 ②에서 ③으로 넘어가는 눈 마주침 직전 0.5초는 배경음악을 거의 무음으로 내리고 숨소리·대기실의 방 소리만 남긴다. 눈이 마주치는 순간 음악을 다시 올린다(가볍고 통통 튀는 어쿠스틱 기타·우쿨렐레·피아노 스타카토).
> 마무리 장치: A 첫 컷 오른쪽 위에 날짜 카드 `사귄 지 7일째`(작은 글씨, 0:00–0:03). D2에서 휴대폰 화면 위에 `소원 하나 더 남았어.`를 얹고, 이어서 1.5초 검은 화면에 `…금방 내려가.`. 선택: 끝 2초에 부드러운 버전의 첫 컷(지금의 두 사람)을 짧게 붙이는 "지금으로" 컷은 이 편에 넣지 않는다(새로 생성하지 않음).

## 생성 후 검수
1. 손: 손가락 다섯 개·자연스러운 마디(주먹과 펼친 손바닥, 멈춘 검지, 깍지 낀 손, 스틱을 쥔 손, 휴대폰을 든 손 포함), 손이 얼굴·옷에 녹지 않음.
2. 얼굴: 택우 은테 둥근 안경·짧은 곱슬·올라간 눈매, 남자친구 애쉬 그레이 반묶음·올라간 눈매·왼쪽 귀 작은 은색 스터드·안경 없음·점 없음, A 채택 스틸과 같은 얼굴. 얼굴·체형이 지금 프로필 그대로이고 앳되게 바뀌지 않았는지.
3. 옷(한 벌 통일 — 설렘·A~D·영상 모두 같음): 택우 흰 가운·윗단추 푼 연한 파란 셔츠·가슴 주머니 펜 두 자루와 작은 확대경·숯색 슬림 바지·어두운 가죽 로퍼(명찰·글씨·로고 없음), 남자친구 오버핏 검정 반팔 티·올리브 와이드 카고 바지·검정 두꺼운 운동화(헤드폰·목걸이 없음).
4. 로고·글씨: 접수대·펜·확대경·휴대폰 화면·신발·시계에 글씨나 로고 없음(날짜 카드와 끝 메시지는 편집 글씨로만).
5. 소품: 선크림 스틱이 한 개만 나오는지(A~C는 가운 주머니 밖으로 뚜껑만, D에서 꺼내 남자친구 손에), 가위바위보 손이 주먹과 펼친 손바닥으로 읽히는지. 동물 없음.
6. 세로 9:16.
7. 영상: 대사 철자·순서, 목소리가 블록마다 비슷한지(택우는 낮고 건조하며 놀리는 결, 남자친구는 날카롭고 비꼬는 빠른 말투를 천천히).
8. 좌우 고정: 설렘·A~D 스틸과 모든 영상에서 택우는 화면 오른쪽, 남자친구는 화면 왼쪽. 클립 사이·컷 사이에 좌우가 뒤바뀌지 않고, 다음 클립이 앞 클립이 끝난 자리·자세에서 시작하는지.
9. C → 설렘 연결: C 클립의 마지막 프레임이 설렘 스틸과 자세·거리가 같은지(나란히 앉아 어깨가 닿을 거리, 깍지 낀 손이 둘 사이 소파 위, 둘 다 앞을 봄, 입술이 닿지 않음).
10. 입술 입맞춤·껴안기가 없는가(볼 입맞춤은 설렘 클립 ④ 한 번뿐, 거절되면 머리 쓰다듬기), 간질간질 포인트(멈춘 이마 톡·존댓말 → 반말 더듬기·깍지·볼 입맞춤 뒤 굳음·스틱 쥐여 주기)가 2개 이상 보이는가, 작품의 버릇·소품(선크림 스틱·이마 톡·가위바위보·가운 단추)이 연인 버전으로 나오는가, 플롯 사실(25년 지기·봄결 피부과의원 대기실·목요일 밤 8시 이후·6월)과 어긋나지 않는가.
11. 표정·몸짓: 감정이 보이는 동작(침 삼킴·숨 멈춤·시선 내리깔기·입술을 살짝 다묾·가운 단추 잠갔다 풀기)으로 나오는지, 당황이 얼굴색이 아니라 동작으로만 보이는지, 웃음이 입을 다문 배시시인지.
12. 피부·조명: 땀·번들거리는 피부·이마 광·젖은 느낌, 플라스틱처럼 매끈한 얼굴·강한 보정 필터, 과한 채도·주황/노랑 색 끼임, 렌즈 플레어·어지러운 그림자·지저분한 반사가 없는지.
13. 인물 시트: 가로 16:9, 얼굴·머리는 기존 시트 그대로이고 옷만 이 편 한 벌로 바뀌었는지, 네 장면(클로즈업·앞·옆·뒤)의 옷·소품이 같고 글씨가 없는지. 남자친구 시트에 목·머리 소품이 없는지.
14. 컷 길이: 설렘 클립 컷이 대략 2/3/2/3초로 나오는지, 짧은 인서트·반응 컷은 4초로 만들어 잘라 썼는지.
15. 키 차이: 택우(약 184cm)가 남자친구(약 177cm)보다 크게 나오는지(소파에 앉아서도 어깨 높이 차이가 보이는지), 남자친구는 슬림한 체형인지.
