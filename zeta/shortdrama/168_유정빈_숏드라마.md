## 편집 순서
> 연결: C 클립의 끝 프레임 = 닿기 직전 스틸 = 입맞춤 클립의 첫 프레임이라 C → 입맞춤은 컷 없이 이어 붙이고, 입맞춤 끝의 이마 맞댄 그림에서 D로 넘어간다.
> 전환: 블록 안과 긴장 구간(C → 입맞춤)은 모두 하드 컷. 시간·장소가 바뀌는 곳만 0.3~0.5초 디졸브(이 편은 한 장소·한 시간이라 디졸브 없음). 스와이프·줌 전환·플래시 같은 화려한 전환 효과는 쓰지 않는다.
> 임계점 정지: C 끝(얼굴 몇 cm에서 숨을 멈춘 정적) → 입맞춤 시작 직전의 0.5~1초는 배경음악을 거의 무음으로 내리고 숨소리·방 소리(가게 냉장고의 낮은 소리)만 남긴다. 입술이 닿는 순간 하드 컷(입맞춤 클립 1컷 → 2컷)과 함께 음악을 다시 올린다.

짧은 컷: 1.5~2초 인서트·반응 컷을 따로 만들 때는 모델의 최소 길이(4초)로 생성하고 `쓸 구간`에 적은 부분만 잘라 쓴다. 컷 길이는 고르게 맞추지 않고 콘티 표의 길이를 따른다.
배경음악은 편집에서 얹고 대사 구간은 음량을 낮춘다. 입 모양과 소리가 어긋나면 편집에서 맞춘다.

## 생성 후 검수
1. 손: 손가락 다섯 개·자연스러운 마디, 손이 얼굴·옷에 녹지 않음, 앞자락을 쥔 손의 은반지가 오른손 검지에 있는지.
2. 얼굴: 정빈 또렷한 쌍꺼풀·오른쪽 눈썹 끝의 작은 흉터·한쪽 입꼬리가 더 올라간 입매·두건 밖으로 삐져나온 머리, 재호 올라간 외꺼풀 눈매·얇은 사각 메탈 안경·애쉬 브라운 가르마 펌·점 없음·흉터 없음, A 채택 스틸과 같은 얼굴.
3. 옷(한 벌 통일 — 닿기 직전·A~D·영상 모두 같음): 정빈 진녹색 앞치마·윗단추 두 개를 푼 숯색 헨리넥(소매를 고르지 않게 걷음)·짙은 작업 바지·검은 주방화·흰 두건, 재호 네이비 니트 조끼·머스터드 옐로 카라 셔츠·짙은 회색 울 바지·갈색 로퍼(목걸이 사원증 없음).
4. 로고·글씨: 앞치마·장부·휴대폰 화면·유리문·신발에 글씨나 로고 없음.
5. 소품: 장부 한 권·연필 한 자루·재호 휴대폰 한 대 — 위치가 이어지는지(A 장부 위 연필 → B 정빈 손 → C 다시 장부 위 → 이후 계속 거기).
6. 세로 9:16.
7. 영상: 대사 철자·순서, 목소리가 블록마다 비슷한지.
8. 좌우 고정: 닿기 직전·A~D 스틸과 모든 영상(입맞춤 클립의 모든 컷 포함)에서 정빈(진녹색 앞치마)은 화면 오른쪽(화면 왼쪽을 봄), 재호(네이비 니트 조끼)는 화면 왼쪽(화면 오른쪽을 봄). 클립 사이·컷 사이에 좌우가 뒤바뀌지 않고, 다음 클립이 앞 클립이 끝난 자리·자세에서 시작하는지.
9. C → 입맞춤 연결: C 클립의 마지막 프레임이 닿기 직전 스틸과 자세·거리가 같은지(장부 위 연필이 손 뒤에, 정빈 손은 재호 팔꿈치 위, 재호 손은 정빈 앞치마 앞자락을 쥠, 얼굴 몇 cm, 입술이 닿지 않음).
10. 표정·몸짓: 감정이 보이는 동작(침 삼킴·두건 매듭 고쳐 매기·앞자락을 쥐는 손·팔짱이 풀림·시선 내리깔기)으로 나오는지, 당황이 얼굴색이 아니라 동작으로만 보이고 입술을 깨무는 그림이 없는지, 웃음이 입을 다문 배시시인지.
11. 피부·조명: 땀·번들거리는 피부·이마 광·젖은 느낌, 플라스틱처럼 매끈한 얼굴·강한 보정 필터, 과한 채도·주황/노랑 색 끼임(펜던트 램프 불빛), 렌즈 플레어·어지러운 그림자·지저분한 반사(유리문)가 없는지.
12. 인물 시트: 가로 16:9, 얼굴·머리는 기존 시트 그대로이고 옷만 이 편 한 벌로 바뀌었는지, 네 장면(클로즈업·앞·옆·뒤)의 옷·소품이 같고 글씨가 없는지.
13. 컷 길이: 입맞춤 클립 컷이 대략 2/4/2/4/3초로 나오는지, 짧은 인서트·반응 컷은 4초로 만들어 잘라 썼는지.
