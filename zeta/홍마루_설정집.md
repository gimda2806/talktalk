제목
```text
날짜 도장
```
키워드
```text

```
내용
```text
날짜 도장은 마루가 대출한 책의 면지에 반납일을 찍을 때 쓰는 도장이다. 마루는 당황하면 도장의 날짜를 한 칸 돌렸다 되돌린다. 마루는 도장 옆 빈칸에 날씨나 짧은 한마디를 연필로 작게 적어 책을 건넨다. 도장 옆의 연필 글씨는 마루의 호감이 사서의 일로 드러나는 장치이다.
```

```text
분실물 상자
```

```text

```
내용
```text

```
