# 주인공 체격·신체 특징 — 3면도(인물 시트)에 살릴 점

> 200개 플롯의 메인 캐릭터(주인공) 프로필 프롬프트와 검수 기록에서 체격·피부·표식·몸에 남은 직업 흔적을 뽑아, 숏드라마 3면도(정면·측면·후면 전신 + 상반신 클로즈업)에 반영하면 좋을 점을 정리했다. 남자친구 칸은 `zeta/user-male-video-looks.md`의 나이·체격 줄이다. (2026-10-14 기준)

## 공통으로 지킬 점

1. **키 차이를 그림으로 보이게.** 3면도는 전신이라 키가 그대로 드러난다. 주인공 시트와 남자친구 시트 프롬프트에 둘 다 키(cm)를 적고, 같은 바닥선·같은 카메라 높이로 그리게 한다. 표의 "남자친구보다 ○cm 큼/작음"을 그대로 넣으면 된다.
2. **체형 실루엣은 표의 체격 칸 그대로.** 어깨 폭·팔다리 길이·종아리처럼 전신에서만 보이는 특징은 측면·후면에서도 같아야 한다. 데이터에 없는 근육량을 더하지 않는다(남자친구는 슬림 규칙).
3. **몸·손 흔적은 상반신 클로즈업과 손에 남긴다.** 얼룩·테이프·굳은살·시계 자국·반지처럼 작은 흔적은 전신 컷에서 사라지기 쉬우니 클로즈업 칸에서 손이 보이게 하고, 위치(왼손/오른손)를 정면·측면·후면에서 바꾸지 않는다.
4. **얼굴 표식 고정.** 점·흉터·주근깨·안경·보조개의 위치(좌/우)와 눈꺼풀(홑꺼풀/속쌍꺼풀/쌍꺼풀)은 네 칸 모두 같게.
5. **피부 톤.** 그을린 톤은 목·팔뚝까지 이어지게(태닝 라인이 있으면 정면·후면 모두), 포슬린 톤은 손등까지 같은 톤.
6. 금지는 그대로: 수염 없음, 붉어짐 없음, 남자친구 시트는 머리·목 소품 없음(주인공 시트는 편마다 숏드라마 파일 기준).
