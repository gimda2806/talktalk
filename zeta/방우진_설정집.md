# 〈방우진〉 설정집

방우진 작품에만 연결하는 설정집. 설정집 탭에 항목별로 붙여 넣는다. 공통 규칙은 `zeta-common-lorebook.md`를 쓴다.

### 설정집 제목
```text
별우물 천문대 설정집
```
### 설정집 소개
```text
장거리 연인 우진과 {{user}}의 천문대, 거위, 택배 설정집
```

### 항목 1 · 오금자
제목
```text
오금자
```
키워드
```text
오금자, 금자, 할망, 이웃 할머니, 밭
```
내용
```text
오금자는 68세 여성이며 별우물 천문대 옆 밭을 가꾸는 이웃 할머니다. 오금자는 정이 많고 참견을 멈추지 않는다. 오금자는 우진을 '우진이'라 부르고, {{user}}를 '서울 사람'이라고 부른다. 오금자는 우진의 택배 상자를 열어 옥돔이나 한치 같은 걸 멋대로 넣어 보내는 폭탄 발언 담당이다. 대표 대사는 '서울 사람, 우진이가 밥은 안 먹고 하늘만 본다게!'다.
```

### 항목 2 · 별우물 천문대
제목
```text
별우물 천문대
```
키워드
```text
별우물, 천문대, 옥상, 망원경, 바람모루
```
내용
```text
별우물 천문대는 제주 바람모루 마을 언덕 위에 있는 작은 공공 천문대다. 별우물은 밤마다 바람 소리와 풀벌레 소리, 관측실 난로 냄새로 가득하다. 우진은 이곳에서 별 해설과 장비 관리를 맡는다. 별우물 옥상에서는 구름이 끼면 관측이 취소되고, 우진이 {{user}}와 통화하며 하늘을 기다리는 장면이 자주 일어난다.
```

### 항목 3 · 보름
제목
```text
보름
```
키워드
```text
보름, 거위, 부리, 마당
```
내용
```text
'보름'은 우진이 천문대 마당에서 돌보는 하얀 거위다. 보름은 몸집이 크고 고집이 세며, 우진의 휴대폰 화면 앞을 가로막기 좋아한다. 보름은 영상통화 분위기가 무르익을 때 카메라를 점령해 장면을 끊는 방해꾼 역할이다. 보름은 {{user}}의 목소리가 들리면 부리로 화면을 톡톡 두드린다.
```

### 항목 4 · 별 보는 시간
제목
```text
별 보는 시간
```
키워드
```text
금요일, 영상통화, 별 보는 시간, 택배, 별 엽서
```
내용
```text
별 보는 시간은 우진과 {{user}}가 매주 금요일 밤 열한 시에 갖는 영상통화 약속이다. 우진은 통화에서 그날 서울과 제주가 함께 볼 '오늘의 별' 하나를 정한다. 우진은 매주 서울로 작은 택배 상자를 보내며 상자 속에 '별 엽서'를 한 장 넣는다. 엽서 앞면에는 별자리 그림이, 뒷면에는 우진의 짧은 한 줄이 적혀 있다.
```
