# 제타(zeta) 캐릭터 제작 포맷

제타에 플롯(캐릭터)을 올릴 때 쓰는 입력 칸 구조, 작성 원칙, 붙여넣기용 템플릿을 한곳에 모은 문서.
`{{user}}`는 유저, `{{char}}`는 캐릭터를 가리키는 제타 치환어.

---

## 1. 화면 구조와 글자 수 제한

| 탭 | 칸 | 제한 | 공개 여부 |
| --- | --- | --- | --- |
| 프롬프트 | 기본 설정 › 제목 | 20자 | 공개 |
| 프롬프트 | 기본 설정 › 설명 (상황·관계·세계관) | 프롬프트 합계 2,400자 | **공개** |
| 프롬프트 | 기본 설정 › 고급 설정 | 미확인 | 미확인 |
| 프롬프트 | 캐릭터 › 이미지 | 최대 5장 (필수) — 우리는 주인공 1장만 쓴다 | 공개 |
| 프롬프트 | 캐릭터 › 이름 | 10자 | 공개 |
| 프롬프트 | 캐릭터 › 설명 | 프롬프트 합계 2,400자 | **공개** |
| 프롬프트 | 캐릭터 추가 | 최대 10명 | 공개 |
| 프롬프트 | 대화 프로필 (유저용) | 최대 5개, 글자 수 제한 미포함 — 우리는 설명 1개 + 유저 이미지 남성용·여성용 2장 | - |
| 프롬프트 | 상황 예시 | 2,000자 (전체 제한 미포함) | - |
| 인트로 | 첫 상황 (말풍선) | 1,500자, 이미지 5장 — 우리는 이미지를 넣지 않는다 | 공개 |
| 소개 | 공개 소개글 | 미확인 | 공개 |
| 스타일 / 플러그인 / 설정 | - | 미확인 | - |

> 주의: 기본 설정 설명과 캐릭터 설명은 공개 화면에 그대로 노출된다. 스포일러는 "떡밥" 형태로만 쓴다.

## 2. 작성 원칙

1. **공개 = 예고편, 설정 = 대본.** 공개되는 칸에는 결말이나 비밀을 직접 쓰지 않고 궁금증을 남기는 문장으로 쓴다.
   - 나쁜 예: "노견 보리를 떠나보낸 뒤 수의사가 되었다."
   - 좋은 예: "책상에는 이제 사진으로만 남은 강아지 '보리'의 액자가 놓여 있다."
2. **예시가 규칙보다 강하다.** AI는 상황 예시와 인트로의 모양을 그대로 따라 한다. 원하는 문체를 예시에서 먼저 보여준다.
3. **서술과 대사는 줄을 나눈다.** 서술은 `*별표*` 안에, 빈 줄 하나, 그다음 줄에 대사.
4. **표는 쓰지 않는다.** 제타는 마크다운 표를 렌더링하지 않아 "항목/설정"이 줄마다 흩어진다. `[항목] 내용` 형식을 쓴다.
5. **장면 전환은 기본적으로 유저가 한다.** 유저가 `*서술*`로 직접 장면을 바꾼다. AI는 공통 설정집 항목 1의 조건(헤어짐·귀가·잠자리로 한 매듭이 지어졌을 때)에서만 다음 날이나 다음 약속으로 넘어간다.

### 성별 겸용(BL·현대 로맨스) 만들기

- `{{user}}`는 모든 글 칸(설명, 인트로, 상황 예시, 설정집)에서 성별 구분 없이 쓴다. 유저 이미지만 남성용·여성용 두 장을 두어 플레이어가 고른다. 남성·여성, 그·그녀 같은 표현과 성별 분기를 쓰지 않는다.
- 호칭은 '이웃분', '작가님'처럼 중립적으로 쓴다.
- 대화 프로필은 성별 구분 없이 하나만 만든다. 설명에 성별을 쓰지 않는다.
- 유저 이름은 플레이어가 직접 정한다. 어디에도 이름을 지어 넣지 않고 `{{user}}`로만 쓴다.
- 인트로 맨 위에 **대화 프로필 선택 시점**을 둔다.
- 성별 관련 규칙은 기본 설정 설명에 쓰지 않고 공통 설정집 항목 3(성별규칙, `zeta-common-lorebook.md`)에서 한 번만 관리한다.

## 3. 붙여넣기 템플릿

### 3-1. 기본 설정 › 제목

```text
(캐릭터 이름. 캐릭터 › 이름 칸과 동일하게 쓴다)
```

### 3-2. 기본 설정 › 설명

```text
[배경] (장소, 시대, 장르. 판타지 요소 유무)
[상황] (이야기가 시작되는 사건. {{user}}가 {{char}}를 계속 만나게 되는 이유)
[관계] ({{user}}와 {{char}}의 현재 관계, 호칭이 바뀌는 조건)
[조연] (선택. 조연이 없으면 이 줄을 생략한다. 이름(나이, 성격 한 줄, 역할))
[진행 원칙] (메인 분위기와 갈등 수위)
[{{char}}의 마음] (결말이 아니라 시작만)
```

### 3-3. 캐릭터 › 이름 / 설명

```text
(10자 이내 이름)
```

```text
(이름)은 (나이) 남성으로 (직업·소속)이다.
(외모: 키, 체형, 머리, 눈매, 특징적인 소품·버릇, 옷차림, 목소리)
(성격: 겉과 속, 반전 포인트, 진지해지는 순간)
(말투: 존댓말/반말, 자주 쓰는 말버릇, 당황할 때 버릇)
(좋아하는 것: 떡밥이 될 만한 소재를 하나 섞기)
```

### 3-4. 대화 프로필 (유저용)

> 이름 칸은 비워두고 플레이어가 직접 입력하게 한다. 설명에는 이름 대신 `{{user}}`를 쓴다.
> 나이, 직업, 성격, 말투, 취향은 쓰지 않는다. 플레이어가 {{user}}를 자유롭게 움직일 수 있게 주인공과의 관계에서 꼭 필요한 사실만 한두 문장으로 쓴다.

```text
{{user}}는 (주인공과의 관계에서 꼭 필요한 사실 한두 문장. 예: 서울에 사는 장거리 연인 / 주인공과 3년째 같이 사는 연인)
```

### 3-5. 상황 예시

```text
{{user}}: (유저 대사)
{{char}}: *(행동·표정 서술)*

(대사)

{{user}}: (유저 대사)
{{char}}: *(행동·표정 서술)*

(대사)

*(이어지는 행동)*

(대사)
```

> 캐릭터 대사 줄은 이름 대신 항상 `{{char}}:`로 시작한다.
> `*...*` 안의 행동 지문은 주어(캐릭터 이름)를 넣어 소설처럼 서술형으로 쓴다. (인트로와 같은 문체)
> 예시는 2~3쌍(한 쌍 = `{{user}}` 한 줄 + `{{char}}` 응답)으로 쓴다. 평소 모습 1~2개와 감정이 달라지는 순간 1개로 구성하면 캐릭터의 온도 차를 학습시킬 수 있다. 모든 예시가 작품의 메인 분위기를 벗어나지 않는다.

### 3-6. 인트로 (말풍선 순서)

1. **대화 프로필 선택 시점** — 맨 위. 이 칸만 따로 붙여 넣는다.
2~6. 나머지 말풍선은 아래 형식으로 **코드블록 하나에 모아 저장**한다. 제타에는 한 번에 붙여넣기가 되지 않으므로, 붙여 넣을 때는 **말풍선 하나씩 따로** 복사한다. (뷰어 제타 탭이 말풍선별로 나눠 준다)

- 내레이터 말풍선은 `@:` 뒤에 내용을 붙여 쓴다. (별표 없이)
- 캐릭터 말풍선은 `{{char}}:`로 시작하고, 별표 `*...*` 안에는 인물의 행동(대본의 지문)만 쓰되, 주어를 넣어 소설처럼 서술형으로 쓴다. (예: `*한결은 회중시계 뚜껑을 열었다 닫으며 헛기침을 한다.*`) 빈 줄 하나 뒤에 대사를 다음 줄에 쓴다.
- 말풍선 사이는 빈 줄 하나로 나눈다.
- 순서는 ②가 내레이터, ⑥이 캐릭터 대사(질문·부탁)로 고정이고, ③~⑤는 내레이터와 캐릭터를 번갈아 두되 작품마다 자유롭게 정한다. 아래는 한 가지 예시 순서다.

```text
@: (시간, 장소, 사건)

@: ({{char}}의 등장과 첫 행동)

{{char}}: *(행동 지문)*

(첫 대사. 짧고 인상적으로)

@: ({{char}}가 {{user}}를 바라보는 서술)

{{char}}: *(행동 지문)*

(유저가 대답하고 싶어지는 마지막 대사. 질문이나 부탁)
```

> 캐릭터 말풍선 안에서도 서술과 대사는 반드시 줄을 나눈다(지문 → 빈 줄 → 대사). 인트로에는 이미지를 넣지 않는다.

### 3-7. 소개 (공개 소개글)

```text
(상황을 보여주는 짧은 문장 2~3줄)

"(캐릭터의 대표 대사)"

(유저가 궁금해질 질문이나 반전 2~3줄)

━━━━━━━━━━

(캐릭터 이름) (나이)
(직업 한 줄)
(성격 한 줄)
(설렘 포인트 한 줄)

━━━━━━━━━━

#장르 #키워드 #캐릭터타입 #분위기
```

> 비밀은 빼고, 플롯 마지막 장면의 떡밥을 한 줄 숨겨두면 좋다. (예: "영수증 뒷면을 확인해 주세요")

## 4. 캐릭터 설계 체크리스트

- [ ] **핵심 성격**: 캐릭터가 어떤 사람인지 한 줄 설명
- [ ] **버릇 하나**: 캐릭터를 나타내 주는 요소. 당황할 때, 마음이 편할 때, 술에 취했을 때처럼 상황에 따라 나오는 버릇과, 분위기가 확 바뀌는 설렘 스위치를 함께 쓴다
- [ ] **갈등 요소 하나 이상**: 오해, 서로 다른 바람, 감춘 마음처럼 일상적인 감정에서 나오는 것. 수위는 루틴 작성 규칙 11의 1~3단계 중 하나 (이별 위기까지 가능하되 확정된 이별로 끝나지 않는다)
- [ ] **주요 이벤트 4~6개 + 에필로그 한 장면**

## 5. 이미지 프롬프트 템플릿

이미지 프롬프트는 주인공 프로필용 1개와 유저 대화 프로필용 2개(남성용·여성용), 모두 세 개를 쓴다. 규칙과 영어 원문 블록은 `zeta-image-prompt-rules.md` 하나에서 관리하며, 이 절은 그 파일을 어떻게 조립하는지만 적는다.

### 5-1. 주인공 프로필용

`zeta-image-prompt-rules.md` 5절의 구성 순서대로 블록을 이어 붙인다. "원문 그대로" 블록은 번역·요약·압축하지 않고 영어 원문을 통째로 넣는다.

1. GLOBAL K-DRAMA IDOL LOOK BLOCK (6-1, 원문 그대로) — 프로필 한 장이면 첫 문장만 `Upper body portrait for a Korean live-action short drama, ultra-photorealistic 2K, NOT illustration.`으로 바꿀 수 있다
2. GLOBAL IDOL FACIAL BEAUTY FLOOR (6-2, 원문 그대로)
3. GENDER BEAUTY AMPLIFIER (6-3, 원문 그대로) — 주인공은 남성이므로 MALE 블록
4. 이 캐릭터의 FACE GEOMETRY BLOCK (6-4) — 작품마다 새로 쓴다
5. ARCHETYPE ADAPTER 또는 캐릭터 성격 디자인 (6-5) — 직업과 성격이 보이게. 핵심 장치(동물·소품)는 선택 사항이며, 있을 때만 넣는다
6. HAIR / BODY / WARDROBE (6-6) — 의상 공통 품질 요건은 원문 그대로
7. `Upper body portrait, three-quarter angle, (표정)` 한 줄 (시트 레이아웃 블록은 쓰지 않는다)
8. LIGHTING MODE 중 하나 (6-8)
9. GLOBAL NEGATIVE BLOCK (6-9, 원문 그대로)

```text
(6-1 원문) (6-2 원문) (6-3 MALE 또는 FEMALE 원문) Face geometry: (이 캐릭터의 얼굴 구조). Character design: (나이대·직업·성격이 드러나는 한 문장, 체형, 머리). Wardrobe: (옷차림). (소품이 있을 때만) Props: (소품, 흐릿한 배경). Upper body portrait, three-quarter angle, (표정). (6-6 의상 품질 요건 원문) (6-8 조명 모드 원문) (6-9 원문)
```

생성 전에 `zeta-image-prompt-rules.md` 7절의 검사표(GLOBAL LITERAL GATE)를 통과해야 한다.

### 5-2. 유저 대화 프로필용 (남성용·여성용 두 개)

유저 이미지는 플레이어가 고르는 자료이므로 **남성용과 여성용 두 개**를 만든다. 대화 프로필 설명 칸은 성별 없이 하나만 둔다. 구성은 5-1과 같고, 성별 블록(6-3)만 각각 MALE/FEMALE을 넣으며 얼굴 구조는 `zeta-image-prompt-rules.md` 6-10의 유저 공통 얼굴을 쓴다. 작품별로 바뀌는 것은 자세·장소·옷차림(·소품)뿐이다.

#### 남성용

```text
(6-1 원문) (6-2 원문) (6-3 MALE 원문) (6-10 유저 공통 얼굴) Character design: a young adult in their twenties, (작품 배경에 맞는 자세와 장소, 옷차림, 소품이 있으면 소품), short neatly cut dark brown-black hair with a light side-swept fringe. Upper body portrait, three-quarter angle facing the viewer, a calm natural expression with a small soft smile. (6-6 의상 품질 요건 원문) (6-8 조명 모드 원문, 주인공과 같은 것) (6-9 원문)
```

#### 여성용

```text
(위와 같되 6-3 FEMALE 원문, 머리는 softly layered dark brown-black hair of shoulder length tucked behind one ear)
```

### 5-3. 한글 설명

각 영문 프롬프트 코드블록 바로 아래에 같은 내용을 한글로 풀어 쓴 설명을 한두 문장으로 덧붙인다. (코드블록 밖)

## 6. 진행 중 장면 운영 팁

- **장면 흐름**: 도입(밀당) → 고조(속마음 살짝) → 끊기(유저가 직접 장면 마무리) → 다음 떡밥(장소·시간 이동)
- **상황 깔기**: 조연을 등장시키거나 장소를 바꿀 때는 `*서술*`로 먼저 상황을 깔아준다.
- **리듬**: "참았다 → 터졌다 → 또 위기" 순서로 감정을 오르내리게 한다.
- **흐름을 바꾸고 싶을 때**: 다시 생성하거나, 대사 끝에 `(분위기만 남기고 여기서 끊기)`처럼 괄호로 방향을 준다.
- **예전 습관이 남을 때**: 설정을 고친 뒤에는 새 대화로 시작해서 확인한다.
