# 제타(zeta) 캐릭터 제작 포맷

제타에 플롯(캐릭터)을 올릴 때 쓰는 입력 칸 구조, 작성 원칙, 붙여넣기용 템플릿을 한곳에 모은 문서.
`{{user}}`는 유저, `{{char}}`는 캐릭터를 가리키는 제타 치환어.

---

## 1. 화면 구조와 글자 수 제한

| 탭 | 칸 | 제한 | 공개 여부 |
| --- | --- | --- | --- |
| 프롬프트 | 기본 설정 › 제목 | 20자 | 공개 |
| 프롬프트 | 기본 설정 › 설명 (상황·관계·세계관) | 프롬프트 합계 2,400자 | **공개** |
| 프롬프트 | 기본 설정 › 고급 설정 | 미확인 | 미확인 |
| 프롬프트 | 캐릭터 › 이미지 | 최대 5장 (필수) | 공개 |
| 프롬프트 | 캐릭터 › 이름 | 10자 | 공개 |
| 프롬프트 | 캐릭터 › 설명 | 프롬프트 합계 2,400자 | **공개** |
| 프롬프트 | 캐릭터 추가 | 최대 10명 | 공개 |
| 프롬프트 | 대화 프로필 (유저용) | 최대 5개, 글자 수 제한 미포함 | - |
| 프롬프트 | 상황 예시 | 2,000자 (전체 제한 미포함) | - |
| 인트로 | 첫 상황 (말풍선) | 1,500자, 이미지 5장 | 공개 |
| 소개 | 공개 소개글 | 미확인 | 공개 |
| 스타일 / 플러그인 / 설정 | - | 미확인 | - |

> 주의: 기본 설정 설명과 캐릭터 설명은 공개 화면에 그대로 노출된다. 스포일러는 "떡밥" 형태로만 쓴다.

## 2. 작성 원칙

1. **공개 = 예고편, 설정 = 대본.** 공개되는 칸에는 결말이나 비밀을 직접 쓰지 않고 궁금증을 남기는 문장으로 쓴다.
   - 나쁜 예: "노견 보리를 떠나보낸 뒤 수의사가 되었다."
   - 좋은 예: "책상에는 이제 사진으로만 남은 강아지 '보리'의 액자가 놓여 있다."
2. **예시가 규칙보다 강하다.** AI는 상황 예시와 인트로의 모양을 그대로 따라 한다. 원하는 문체를 예시에서 먼저 보여준다.
3. **서술과 대사는 줄을 나눈다.** 서술은 `*별표*` 안에, 빈 줄 하나, 그다음 줄에 대사.
4. **표는 쓰지 않는다.** 제타는 마크다운 표를 렌더링하지 않아 "항목/설정"이 줄마다 흩어진다. `[항목] 내용` 형식을 쓴다.
5. **장면을 끊는 건 유저.** AI는 스스로 멈추는 걸 어려워한다. 장면 전환은 유저가 `*서술*`로 직접 한다.

### 성별 겸용(BL·현대 로맨스) 만들기

- 설명과 인트로에서 `{{user}}`의 성별을 정하지 않는다.
- 호칭은 '보호자님', '작가님'처럼 중립적으로 쓴다.
- 대화 프로필은 성별 구분 없이 하나만 만든다. 설명에 성별을 쓰지 않는다.
- 유저 이름은 플레이어가 직접 정한다. 어디에도 이름을 지어 넣지 않고 `{{user}}`로만 쓴다.
- 인트로 맨 위에 **대화 프로필 선택 시점**을 둔다.
- 기본 설정 설명에 아래 줄을 넣는다.

```text
[성별] {{user}}의 성별은 정해져 있지 않다. {{char}}는 {{user}}의 성별에 따라 태도나 호칭을 바꾸지 않으며, 성별 고정관념적인 표현을 쓰지 않는다.
```

## 3. 붙여넣기 템플릿

### 3-1. 기본 설정 › 제목

```text
(캐릭터 이름. 캐릭터 › 이름 칸과 동일하게 쓴다)
```

### 3-2. 기본 설정 › 설명

```text
[배경] (장소, 시대, 장르. 판타지 요소 유무)
[상황] (이야기가 시작되는 사건. {{user}}가 {{char}}를 계속 만나게 되는 이유)
[관계] ({{user}}와 {{char}}의 현재 관계, 호칭이 바뀌는 조건)
[조연] (이름(나이, 성격 한 줄, 역할))
[진행 원칙] (분위기, 장면을 끊는 방해 요소)
[성별] (성별 겸용일 때만)
[{{char}}의 과거] (떡밥 형태로)
[{{char}}의 마음] (결말이 아니라 시작만)
```

### 3-3. 캐릭터 › 이름 / 설명

```text
(10자 이내 이름)
```

```text
(이름)은 (나이) (성별)으로 (직업·소속)이다.
(외모: 키, 체형, 머리, 눈매, 특징적인 흉터·소품, 옷차림, 목소리)
(성격: 겉과 속, 반전 포인트, 진지해지는 순간)
(말투: 존댓말/반말, 자주 쓰는 말버릇, 당황할 때 버릇)
(좋아하는 것: 떡밥이 될 만한 소재를 하나 섞기)
```

### 3-4. 대화 프로필 (유저용)

> 이름 칸은 비워두고 플레이어가 직접 입력하게 한다. 설명에는 이름 대신 `{{user}}`를 쓴다.

```text
{{user}}는 (나이). (직업, 생활 패턴). (성격 한 줄과 이야기 시작 계기와 연결된 특징)
```

### 3-5. 상황 예시

```text
{{user}}: (유저 대사)
(캐릭터 이름): *(행동·표정 서술)*

(대사)

{{user}}: (유저 대사)
(캐릭터 이름): *(행동·표정 서술)*

(대사)

*(이어지는 행동)*

(대사)
```

> 예시 하나는 코믹·설렘, 하나는 진지한 순간으로 구성하면 캐릭터의 온도 차를 학습시킬 수 있다.

### 3-6. 인트로 (말풍선 순서)

1. **대화 프로필 선택 시점** — 맨 위
2. **내레이터** — 시간, 장소, 사건 (별표 없이)
3. **내레이터** — {{char}}의 등장과 첫 행동
4. **{{char}}** — 첫 대사 (짧고 인상적으로)
5. **내레이터** — {{char}}가 {{user}}를 바라보는 서술
6. **{{char}}** — 유저가 대답하고 싶어지는 마지막 대사 (농담이나 질문)

> 서술과 대사는 반드시 다른 말풍선으로 나눈다. 장면 이미지는 이미지 칸(0/5)에 넣어 첫 말풍선 위에 둔다.

### 3-7. 소개 (공개 소개글)

```text
(상황을 보여주는 짧은 문장 2~3줄)

"(캐릭터의 대표 대사)"

(유저가 궁금해질 질문이나 반전 2~3줄)

━━━━━━━━━━

(캐릭터 이름) (나이)
(직업 한 줄)
(성격 한 줄)
(설렘 포인트 한 줄)

━━━━━━━━━━

#장르 #키워드 #캐릭터타입 #분위기
```

> 비밀은 빼고, 플롯 마지막 장면의 떡밥을 한 줄 숨겨두면 좋다. (예: "영수증 뒷면을 확인해 주세요")

## 4. 캐릭터 설계 체크리스트

- [ ] **반전 한 줄**: 겉과 속이 다른 지점 (예: 무서운 덩치 ↔ 소심한 대형견)
- [ ] **버릇 하나**: 거짓말·당황할 때 하는 행동 (예: 바코드 스캐너 만지작, 안경 고쳐 쓰기)
- [ ] **연결 고리 동물·소품**: 둘 사이를 이어주고 장면을 끊어주는 장치 (고양이, 앵무새, 쪽지)
- [ ] **설렘 스위치**: 분위기가 확 바뀌는 조건 (목소리가 낮아질 때, 장난기가 사라질 때)
- [ ] **신파 떡밥 하나**: 마음을 연 상대에게만 꺼내는 과거
- [ ] **코믹 조연 하나**: 눈치 빠른 친구, 폭탄 발언 담당 어른 등
- [ ] **주요 이벤트 3개 이상 + 에필로그 한 장면**

## 5. 이미지 프롬프트 템플릿

```text
Korean webtoon style, semi-realistic manhwa illustration, upper body portrait of a (나이)-year-old Korean (man/woman), (체형), (머리 모양·색), (눈매), (피부), (표정), (옷차림), (소품), plain light gray background, soft lighting, high detail
```

장면용은 배경을 `(장소), (시간대·날씨), cinematic soft lighting`으로 바꾼다.

## 6. 진행 중 장면 운영 팁

- **장면 흐름**: 도입(밀당) → 고조(속마음 살짝) → 끊기(유저가 직접 장면 마무리) → 다음 떡밥(장소·시간 이동)
- **상황 깔기**: 조연을 등장시키거나 장소를 바꿀 때는 `*서술*`로 먼저 상황을 깔아준다.
- **리듬**: "참았다 → 터졌다 → 또 위기" 순서로 감정을 오르내리게 한다.
- **흐름을 바꾸고 싶을 때**: 다시 생성하거나, 대사 끝에 `(분위기만 남기고 여기서 끊기)`처럼 괄호로 방향을 준다.
- **예전 습관이 남을 때**: 설정을 고친 뒤에는 새 대화로 시작해서 확인한다.
