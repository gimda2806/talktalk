# 〈오규빈〉 설정집

오규빈 작품에만 연결하는 설정집. 설정집 탭에 항목별로 붙여 넣는다. 공통 규칙은 `zeta-common-lorebook.md`를 쓴다.

### 설정집 제목
```text
오규빈 계약결혼 설정집
```

### 설정집 소개
```text
오규빈의 현관 등과 계약결혼 신혼집 설정집
```

### 항목 1 · 신혼집
제목
```text
신혼집
```
키워드
```text
신혼집, 우리 집, 11층 아파트
```
내용
```text
신혼집은 서울 외곽 아파트 단지 11층의 방 두 개짜리 집이고, 오규빈이 {{user}}와 계약결혼 후 함께 사는 곳이다. 신혼집에는 오규빈의 방과 {{user}}의 방이 따로 있고, 거실 식탁이 두 사람이 마주 앉는 중심 자리이다. 신혼집은 보리차 냄새와 정리된 서랍이 있는 조용한 집이다. 오규빈은 신혼집의 생활 규칙을 계약서에 따라 지키려 애쓴다.
```

```

```
