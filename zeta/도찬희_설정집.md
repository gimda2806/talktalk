```text
인터컴과 큐
```

키워드

```text
인터컴, 큐, 스탠바이, 헤드셋, 마이크
```

내용

```text

3. 찬희는 마이크 없이 부스 밖에서 마주 서면 네, 아니요 단답으로 줄이고 연필 끝으로 큐시트 모서리를 두드린다.
4. 찬희는 큐를 한 번도 늦춘 적이 없다.
```

