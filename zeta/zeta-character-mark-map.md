# 캐릭터 ↔ 회사 마크 매핑표

공유용 참고 문서입니다. 뷰어에는 표시하지 않습니다.

- 만든 날: 2026-10-11 · 근거: [`zeta-works-list.md`](zeta-works-list.md)(직업·배경) + [`zeta-workplace-map.md`](zeta-workplace-map.md) + 이미지 프로필 제작 폴더의 맵 문서 3종(`talktalk-character-workplace-map.md`·`company-mark-requests.md`·`id-badge-exceptions.md`) + 마크 파일 실물
- 마크 이미지는 [`zeta/marks/`](marks/)에 있습니다. 시안이 여러 개인 마크는 **마지막 생성본이 최종**이라 최종본만 올렸습니다.
- 이 표가 **우선 기준**입니다. 표에 없는 인물(= '대상 아님')에게는 마크를 넣지 않습니다. 마크는 가슴에 건 사원증·출입증에만 넣고, 의상·배경·장비에는 넣지 않습니다.
- 파일명은 정확히 이 표의 것을 씁니다. 철자가 비슷한 마크가 많아 혼동하기 쉽습니다 (예: 법무법인 청솔 ≠ 청솔 회계법인, 여백 출판사 ≠ 여백 미술관, 한울방송 ≠ 이음새 포스트).

## 상태 뜻

| 상태 | 뜻 | 이미지에 마크를 넣나 |
| --- | --- | --- |
| 확정 | 맵에서 인물·적용 범위까지 정해짐 | **넣는다** (적용 범위 열을 따름) |
| 마크 있음·범위 미확정 | 마크 파일은 있는데 어떤 이미지(주인공/유저)에 넣을지 아직 확정 안 됨 | **사용자 확인 후** 넣는다. 확인 전에는 임의로 넣지 않는다 |
| 마크 없음 | 소속은 분명한데 마크 파일이 없음 | 넣지 않는다 (새 마크를 만들지 않는다) |
| 대상 아님 | 개인 사업장·자영업·프리랜서·학생 등 | 넣지 않는다 |

## 3. 혼동 주의·확인 필요

- **임하준 vs 홍마루**: 로컬 맵은 `mulphure-library-mark-v1.png`(물푸레 도서관)를 임하준에게 붙였지만, 작품 목록상 물푸레 도서관 사서는 홍마루이고 임하준은 '구립 어린이도서관 사서'입니다. 이미 만든 임하준 이미지가 있다면 확인이 필요합니다.
- **백규휘**: 저장소 맵은 담백푸드 마크 확정, 로컬 맵에는 없습니다. 주인공만 해당, 유저(거래처 사장)는 마크 없음.
- **금석주**: 유저 이미지만 법무법인 청솔 마크. 주인공은 청솔 빌딩 1층 카페 사장이라 마크 없음.
- **시안이 여러 개인 마크 → 마지막 생성본이 최종** (사용자 지정): 다올일보 `v5-new`, 들보 건축사무소 `v2`, 해담제과 `v3`, 오솔초 `v2`, 방송·공연 스태프 `staff-v3`, 소금 애드 `.jpg`. 나머지 버전은 이전 시안이라 쓰지 않습니다. 같은 이름 파일이 둘이면 수정 시각이 더 나중인 것을 씁니다.
- **여백**: 여백 출판사(문세형, 마크 있음) ≠ 여백 미술관(목유한, 마크 없음).
- **이음**: 이음 엔터테인먼트(강엽, 마크 없음) ≠ 이음새 포스트(윤미르, 마크 있음) ≠ 이음 수학학원(이시우, 마크 없음).
- **봄볕**: 봄볕 소아청소년과의원(권성환, 마크 없음) ≠ 봄볕 어린이집(기범석, 사원증 불필요).
- **한울방송 마크**는 있으나 출연자(서진호 앵커·권이현 배우)에게 적용할지 미정. 스태프(김산들 조연출·연강묵 작가)는 적용 가능성이 높습니다.
- **스태프 공통 마크**(`broadcast-performance-crew-staff-mark-v3.png`)는 전용 회사 마크가 없는 현장 스태프(도찬희·곽단우·서준혁·강엽 등)에만. 전용 마크가 있으면(여밈 스타일링·이음새 포스트·한울방송 등) 그쪽이 우선입니다.
