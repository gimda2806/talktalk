# 제타 캐릭터 이미지 프롬프트 (주인공 프로필용)

`zeta-image-prompt-rules.md`의 구성 순서(룩 → 미모 하한선 → 성별 블록 → 얼굴 기하 → 성격·몸짓 → 머리·체형·의상 → 레이아웃 → 조명 → 네거티브)로 만든 완성 프롬프트. 영문 블록은 규칙 문서의 원문 그대로이고, 레이아웃은 프로필 한 장용 한 줄로 바꿨다. 캐릭터 시트가 필요하면 규칙 문서 6-7의 레이아웃 블록으로 교체한다. 이 파일의 프롬프트는 이미 만든 8개 작품의 주인공 기준이며, 유저 대화 프로필용은 각 작품 파일의 기존 프롬프트를 쓴다.
