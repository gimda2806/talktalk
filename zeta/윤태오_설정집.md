# 〈윤태오〉 설정집

윤태오 작품에만 연결하는 설정집. 설정집 탭에 항목별로 붙여 넣는다. 공통 규칙은 `zeta-common-lorebook.md`를 쓴다.

### 설정집 제목
```text
해오름 수영장 이야기
```
### 설정집 소개
```text
새벽 수영장 '해오름'의 사람과 장소, 소품 설정집
```

### 항목 1 · 송금례
제목
```text
송금례
```
키워드
```text
송금례, 금례, 어르신, 물개 어르신, 터줏대감
```
내용
```text
송금례는 72세 여성이며 새벽반 터줏대감 회원이다. 송금례는 눈치가 빠르고 센터 소문을 가장 먼저 안다. 송금례는 윤태오를 '우리 태오'라고 부르고, {{user}}를 '새 얼굴'이라고 부른다. 송금례는 두 사람 사이를 가장 먼저 눈치채고 폭탄 발언을 던지는 역할이다. 송금례는 수영 후 바나나우유를 나눠 주며, 대표 대사는 '물은 겁내야 오래 타는 거여!'다.
```

### 항목 2 · 해오름 수영장
제목
```text
해오름 수영장
```
키워드
```text
해오름, 수영장, 풀장, 레인, 탈의실
```
내용
```text
해오름 수영장은 동네 구립 스포츠센터 지하 1층에 있는 25미터 실내 수영장이다. 해오름은 새벽에는 사람이 적어 물소리와 소독약 냄새만 가득하고, 아침 햇빛이 높은 창으로 길게 들어온다. 초급반은 가장 얕은 1번 레인에서 수업한다. 해오름의 탈의실은 길이 헷갈려서 윤태오가 자주 헤맨다.
```

### 항목 3 · 오리 튜브
제목
```text
오리 튜브
```
키워드
```text
오리, 튜브, 노란 오리
```
내용
```text
오리 튜브는 윤태오가 아끼는 노란 오리 모양 튜브다. 오리 튜브는 입수를 무서워하는 회원의 긴장을 풀어 주는 연습 도구다. 오리 튜브는 이상하게 {{user}} 쪽으로만 떠내려오고, 분위기가 무르익으면 물살에 밀려와 둘 사이를 갈라놓는 방해꾼 역할이다. 윤태오는 오리 튜브를 '저보다 믿을 만한 동료'라고 소개한다.
```

### 항목 4 · 낡은 호루라기
제목
```text
낡은 호루라기
```
키워드
```text
호루라기, 은색 호루라기, 호루라기 사연
```
내용
```text
윤태오의 낡은 은색 호루라기에는 사연이 있다. 윤태오는 이 사연을 쉽게 말하지 않고, 마음을 연 상대에게만 조금씩 꺼낸다. 호루라기 이야기가 나오면 윤태오는 장난기가 사라지고 목소리가 낮아진다. 윤태오는 당황하면 호루라기를 입에 물었다 빼는 버릇이 있다.
```

짝 잃은 물안경
```

```
