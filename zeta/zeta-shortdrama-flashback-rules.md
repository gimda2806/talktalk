# 숏드라마 콘티 — 회상씬 공통 규칙

> 2026-10-15 사용자 결정: "이미 연인이나 부부인 설정인 경우에는 회상씬으로 콘티 작성." 플롯의 **지금 시점**에서 두 사람이 이미 연인·부부(○년째 연애, 결혼 ○년차, 동거 중 등)인데, 콘티가 그보다 **앞선 시기**(연인으로 발전하는 순간 · 연애 초기)를 그릴 때 이 규칙을 쓴다. 쓰는 곳: `zeta/zeta-shortdrama-confess-routine-prompt.md`(연인 발전 버전), `zeta/zeta-shortdrama-earlylove-routine-prompt.md`(연애 초기 버전). 첫만남 버전은 이미 자체 규칙(날짜 카드·연결 카드)이 있어 바꾸지 않는다.

## 판단

- 작품 파일 `## 0. 기획 요약`·`## 3. 소개 탭`·`## 4. 설정집`에 "○년째 연애/연인/결혼/부부/동거"가 지금 상태로 적혀 있으면 **회상씬**.
- 플롯이 아직 연인이 아닌 상태에서 시작하면(첫 손님·짝사랑·계약 등) 회상이 아니라 **플롯 이후의 현재 진행형**으로 쓴다(회상 장치 없음).
- 설명 줄에 `회상씬 — 지금: {플롯의 지금 관계 한 줄} / 그때: {○년 전 장면}` 또는 `현재 진행형 — 플롯 이벤트 N 이후`를 적는다.

## 회상 장치 (편집 중심 — 생성 프롬프트는 거의 그대로)

1. **여는 지금 컷 (2~3초):** 지금의 두 사람(부부라면 결혼반지, 지금 옷)이 그때를 떠올리게 하는 계기 하나 — 같은 장소·같은 소품·같은 말. 새로 만들지 않고 **부드러운 버전의 컷이나 스틸을 재사용**한다(편집 칸에 어떤 컷을 쓰는지 적는다). 없으면 계기 소품 클로즈업 스틸 한 장만 새로 쓴다(인물 없이 손·소품만).
2. **넘어가는 전환 (0.5~1초):** 소품 클로즈업에서 초점이 풀렸다가 다시 맞으면 그때 — 디졸브 또는 화이트 플래시. 소리는 지금의 공간음이 줄며 그때의 음악이 들어온다.
3. **회상 본편:** 각 버전 규칙의 A~D·클립 그대로. 색은 **편집에서** 입힌다: 살짝 따뜻하고 바랜 톤, 옅은 필름 그레인, 가장자리 부드러운 비네트. **생성 프롬프트에는 회상·과거·`young`·`flashback`·흑백을 넣지 않는다**(얼굴이 바뀌거나 앳되어지는 것을 막는다). 얼굴·체형은 지금 프로필 그대로, 다른 것은 옷·머리 길이처럼 플롯이 말하는 그때의 사실만.
4. **날짜 카드:** 회상 본편 첫 컷 오른쪽 위에 `○년 전 · …`(각 버전 규칙의 문구). 편집 글씨.
5. **돌아오는 지금 컷 (2초, 필수):** 회상의 마지막 대사·표정 뒤, 지금의 두 사람이 같은 동작을 하는 짧은 컷(같이 웃거나, 같은 손깍지 — 부부면 반지가 보이게). 원색 톤으로 돌아온다. 부드러운 버전 컷 재사용을 먼저 고려하고, 새로 써야 하면 「기본 규칙」 시작 스틸 규칙대로 지금 의상으로 한 장.
6. **음성:** 회상 본편 대사는 그대로 동시녹음 톤. 지금 컷에 한 줄 내레이션을 쓸 때는 둘 중 한 사람만, 한 줄만(예: `그때 네가 먼저 잡았잖아.`).

## 파일에 적는 곳

- 설명 줄(`>`)에 판단 결과(회상씬/현재 진행형)와 근거.
- 콘티 표 맨 앞 줄에 `0 · 지금(회상 계기)`, 맨 끝 줄에 `E · 지금으로`를 추가하고, 재사용할 컷 이름을 적는다.
- `## 편집 순서` 맨 위에 "지금 → 전환 → 회상(색보정) → 지금" 한 줄과 색보정 값(따뜻하게 +, 채도 약간 −, 그레인 약하게, 비네트 약하게).
- `## 생성 후 검수`에 "회상 본편의 얼굴이 지금과 같은 사람으로 보이는가(앳되게 바뀌지 않았는가), 지금 컷과 회상 컷의 옷이 구분되는가, 부부면 지금 컷에만 반지가 있고 회상에는 플롯상 맞는 경우에만 있는가".
